## چه چیزی در آرشیو است؟

تمام فایل‌های فضای کاری پروژه، شامل `results/`، `output/`، فایل‌های ساخت و نسخه‌های میانی در `.build/`، و فایل‌های بایگانی‌شدهٔ قبلی نگهداری می‌شوند. مسیرهای آزمایشیِ ناموفق، خروجی خام، کدهای نسخه‌دار، گزارش‌ها و اسلایدها حذف نشده‌اند. سند موجود در پوشهٔ دیگر پروژه با ثبت منشأ در `archive/external_sources/` آمده است. همهٔ شاخه‌های محلی Git نیز به مخزن ارسال می‌شوند. پوشهٔ داخلی `.git/` به‌صورت فایل بارگذاری نمی‌شود؛ تاریخچه از طریق خود Git منتقل می‌شود.

## دامنهٔ ادعای الگوریتم

حل‌گر فعلی افرازهای سازگار با برچسب‌های دقیقِ کلمهٔ کامل را برای عوامل مستقلِ منظم با الفباهای مجزا، تحت مجموعهٔ معتبرِ تعدادهای مجاز، بررسی می‌کند. نتیجهٔ قطعی دربارهٔ مولد واقعی مشروط به درست‌بودن همین فرض‌هاست. مشاهده‌نشدن یک تریس، برچسب منفی نیست. شمارش افرازها، احتمال مالکیت فیزیکی نیست. پوشش همگانیِ صددرصدِ ساختار سخت‌افزاری از هر لاگ متناهی ادعا نمی‌شود.

نسخهٔ اجرایی C009 روی ۱۲۹ مجموعهٔ کامل افراز با مرجع مستقل تطبیق داشت؛ مورد ۱۴نمادیِ آزمون مقیاس ناتمام ماند. جزئیات و محدودیت‌ها در گزارش همان دور ثبت‌اند.
