# Independent logic certificate checker

`checker.py` implements the separate V34 logic verification request from `certification/IMPLEMENTATION_PROFILE_R1_EN.md` and its bound certificate spec using only the Python standard library. It reconstructs CNF from the separately supplied instance and checks direct projections and both branches of the refutation tree. It does not import the solver, historical engines, or third-party libraries. Hypergraph certificates are outside this checker and return INCOMPLETE after basic envelope validation; this is not a mathematical rejection.

CLI: pipe one UTF-8 JSON request to `python checker.py`; stdout is one JSON verifier response. Strict raw JSON rejects duplicate keys, BOM, non-UTF-8, floats/exponents, non-finite values, trailing data, and unpaired surrogates. Programmatic `verify(request)` accepts already-decoded Python JSON values and returns a response dictionary; it cannot detect duplicate keys or numeric spellings lost in a caller's parser, so callers needing wire validation must use `strict_load(bytes)` first. Large JSON integers are supported by disabling Python's decimal digit cap; there is no fixed input size cap, so memory/time limits must be imposed externally when required. Tree node budget applies to verification visits, including root, and zero means INCOMPLETE when a tree is required. Recursion or caught memory/time interruption returns INCOMPLETE; external process termination may yield no response. There is no internal timer. Formula construction, gate truth tables and proof verification may consume exponential time and space. Input bytes and parsed tree are held in memory; branch path assignments are copied.

Sanity checks run after implementation authorization on bundled Python 3.12: empty-alphabet optimum and infeasibility, singleton optimum, zero node limit, invalid infeasibility conflict, a two-branch proof, duplicate keys, fractional JSON, trailing material and BOM all returned expected outcomes. This is not an independent audit or an exhaustive test suite; no performance benchmark was run. Further audit is required before use.
