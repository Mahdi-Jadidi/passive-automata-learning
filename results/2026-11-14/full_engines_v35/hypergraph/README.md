# V35 hypergraph implementation

`candidate.solve(data, *, max_candidates=None)` returns the frozen reference's full Python result dictionary for completed calls. Inputs are `alphabet`, `positive`, `negative`, and direct Python strings follow the reference domain including nonempty surrogate-containing strings. Bell-number preflight matches returned budget outcomes under normal completion; it does not literally traverse the reference's candidate prefix. No prior solving engine is imported or called. Search is mixed-cover row enumeration with least-symbol anchored block recursion; fundamental novelty remains OPEN.

`certificate.certify(request)` is a separate V34-profile request interface: `request` has exactly `instance`, `kind: "hypergraph"`, and `limits: {"max_nodes": null or nonnegative integer}`. It returns `status` and `certificate`. `python certificate.py` accepts one strict JSON request on stdin and emits one response on stdout. JSON is UTF-8 without BOM; duplicate decoded keys, noninteger numeric forms, nonfinite values, extra data, and unpaired surrogate code points are rejected. The certificate interface has the scalar-string restriction of the V34 profile, unlike direct `solve`. A maximum input of 8,000,000 bytes is enforced; exceeding it returns INCOMPLETE. Node limit counts proof-construction nodes in preorder, including root, and is checked before node entry. Full search for a candidate and independent verification work are separate from that count. Python recursion and memory may cause INCOMPLETE in certificate calls; hard process termination can produce no output.

The producer self-checks the witness and the tree using rebuilt row tags, but an independent checker must verify the exact certificate against the independently supplied instance. The certificate covers one optimum or infeasibility only; it does not certify counts or witness order. Direct full-output calls have no separate certificate. Memory and runtime are exponential; candidate rows may number 2^m−1 and full tree nodes are at most (m+1)Bell(m), excluding per-node and projection costs. This is an implementation, not a speed or novelty claim.

Smoke check only: 29 two-symbol/empty-alphabet instances including all 27 ternary labelings of ε, a, b, each tested at limits None, 0, 1, 2, 3 against the historical reference as an explicitly disclosed test oracle; 145 complete result comparisons matched. Two empty-alphabet certificate calls returned OPTIMAL and INFEASIBLE respectively. This is not an independent audit or comprehensive proof and no benchmark was run.
