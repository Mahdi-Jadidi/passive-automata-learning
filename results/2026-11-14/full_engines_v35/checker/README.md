# Independent mixed-cover certificate checker

`hypergraph_checker.py` implements the V34-profile hypergraph verifier, reconstructing original projections and every required branch independently of candidate code. It uses Python standard library only and does not import any engine. `verify(request)` accepts an already-decoded Python object; `strict_load(raw_bytes)` enforces strict JSON duplicate-key, integer-lexeme, UTF-8, trailing-data, BOM and Unicode requirements before `verify`. CLI reads one UTF-8 request from stdin and outputs one JSON response. Already-decoded objects cannot retain duplicate keys or original number lexemes. Logic certificates return INCOMPLETE: use the separately maintained V34 logic checker.

max_nodes counts visited DFS nodes including root; zero returns INCOMPLETE when checking is needed. Input and tree are held in memory; no fixed size/time cap is imposed, external controls may stop the process, and caught memory, recursion, overflow, timeout or keyboard interruption return INCOMPLETE. Hard termination can yield no response. Formula-independent coverage recomputation and explicit branches can be exponential. Integer parsing disables the default digit cap to preserve arbitrary precision. This checker certifies one optimum or infeasibility only, not counts, canonical witnesses, or physical ownership.

Initial focused checks: empty optimum, empty infeasibility, singleton optimum, zero node limit, invalid uncovered leaf, one-symbol infeasibility tree and strict JSON malformed inputs returned expected statuses. This is not an independent audit of this checker or exhaustive testing.
