# V35 full-output SAT candidate

`candidate.py` exposes `solve(data, *, max_candidates=None)` and uses only Python standard-library `itertools`. It adapts the independently developed V34 logic CNF builder (`independent_engines_v34/implementation/logic/solver.py`, SHA-256 `8DDB5F63189DC24BAC7C267A92B75A6546D069E8AF935C2C1257B0CE4FB85EC6`), with a separate SAT decision routine and canonical-y blocking. It does not import or call the reference or any historical partition engine. It implements the Python interface, not a JSON wire interface.

`max_candidates` uses Bell preflight after validation and contradiction checks: returned values match the reference budget contract in normal completed execution, but literal canonical prefix traversal, partial progress, timing and interruption behavior do not. SAT discovery and blocking exhaustively enumerate canonical y models. Limits per formula/search: 2,000 Boolean variables, 200,000 clauses, 200,000 visited decision nodes per SAT call and 100,000 models. Python recursion and memory are additional limits. Caught interruption or resource exhaustion returns INCOMPLETE with null mathematical fields. Hard process termination may produce no response. Counts are not certified by the V34 one-optimum checker; independent count-proof support remains open.

Author smoke checks compared the frozen reference on five focused cases: empty feasible and infeasible alphabets, a tied-optimum three-symbol example, contradiction with zero budget, and exhausted budget. All five matched. These checks are not an independent audit, proof of full compatibility, or benchmarks. No public default is changed.
