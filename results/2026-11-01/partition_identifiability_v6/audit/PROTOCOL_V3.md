# C006 protocol v3 addendum

This addendum retains v1/v2 unchanged and freezes the theory lead's examples
for independent exact review. It adds the original and reduced graph-gap
examples, nonunique maximal-refinement example, and both finite samples for the
infinite irreducible target. The manager's 4-symbol candidate remains a
separate v2 extension. All examples receive audit-only grammar sidecars; no
hidden grammar or partition is supplied to a solver. The infinite-target
irreducible examples use the exact language `(ab)*`; other finite samples use a
one-factor infinite regular completion with a unary tail longer than every
observed word. All examples are processed by a new oracle source filename,
without overwriting v1 outputs. No provider/timing authorization is implied.
