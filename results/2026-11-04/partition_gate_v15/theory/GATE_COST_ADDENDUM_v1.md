# C015: the gate is a logical contract, not a universally cheap precheck

The exact prerequisite is singleton ownership version space. Enforcing
“release a partition only after certification” changes the output contract;
it does not imply an independent inexpensive test exists before inference.
On some samples, proving that the first feasible answer is the only answer
requires the same complete search needed for exact uniqueness inference.

Sound unary/count/atom shortcuts can certify particular families cheaply.
They are sufficient routes within the complete procedure, not a universal
polynomial-time prerequisite checker. The fallback broadens coverage beyond
those routes, at potentially exponential computational cost. No NP-hardness
claim for this problem is inferred from that upper bound or from timeouts.

Two feasible distinct models certify observational ambiguity immediately.
A deadline before the needed proof finishes certifies only computational
nonfinality; it must not be relabelled insufficient observational information.

For consistent finite labels and no count constraint, the one-block regular
language P always fits. Thus a nontrivial feasible answer already has a
different one-block alternative. Meaningful unique multi-device ownership
needs explicit valid additional constraints; source speed or a better gate
cannot create that information. Some inputs still uniquely force one block.

The goal is a correct conditional declaration on every completed case, with
honest unresolved outputs when proof is unfinished, not a promise of unique
physical recovery or low cost on all inputs. No runtime or source changes.
