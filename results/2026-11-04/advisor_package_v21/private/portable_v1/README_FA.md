پس از استخراج ZIP، از همین پوشه اجرا کنید: python demo/run_demo.py
فقط Python با کتابخانهٔ استاندارد لازم است. پنج مثال کوچک، خروجی‌ها را نشان می‌دهند.
کد اصلی حل‌گر C2 در algorithm بدون تغییر کپی شده؛ فقط مسیر رابط و دمو برای بستهٔ مستقل تنظیم شده است.
تریس‌های بزرگ و آرشیو خام برای کوچک‌ماندن این بسته اضافه نشده‌اند. گزینهٔ --large اینجا غیرفعال است.
این بسته گزارش پیشرفت با فرض‌های صریح است؛ نوآوری جامع، بازیابی عمومیِ دادهٔ واقعی و بهبود RPNI را ادعا نمی‌کند.
