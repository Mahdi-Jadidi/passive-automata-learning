## Strict event contract to freeze with implementation

Retain source file/record/action positions in a protected provenance sidecar. Chronology is original record order, Blue then Red. Current action at record i obtains its observed status only from the same actor's next record i+1. Exact integer1=positive, integer3=negative; integer2, missing, any other type/value=unlabeled, with distinct reason counters. In Python booleans are not accepted as integers. No last-record invented label; retain its event as unlabeled history if parser supplies it. Failed and unlabeled actions still update histories. Preserve gaps and unknown outcomes, never delete them before a suffix is formed. Check alignment using bounded hand-reviewed raw excerpts and synthetic controls; do not trust upstream converter, which maps UNKNOWN to positive.

Each source file resets all local histories. No cross-file continuation. Current event is excluded from prior history, then appended after predicting. Past labels/outcomes are excluded from symbols and contexts. Preserve full event stream and event boundaries. Atomic symbolization is a new event-level experiment, not a reproduction of paper's parameter-token alphabet. Freeze exact visible-field allowlist and opaque-ID algorithm before GO. Opaque IDs must be stable across splits and independent of labels, host truth and TrueState. Missing observable parameters must have explicit encoding; no silent lookup from hidden simulator state. If target resolution needs observations or network mapping, record its input whitelist and separately quarantine it from the learner. TrueState, observations, host/device mappings, filename IDs and actor/source ordinals must not appear in learner payloads unless the observation model explicitly preregisters them; audit should reject undeclared features.

## Model and conflict criterion

For candidate partition P of a selected symbol set S, block B containing current symbol a, prior stream h from this file, and d in {0,1,2,4,8,full}, key=(a, suffix_d(project_B(h))). d counts preceding events, not current action. d=0 has empty history; full retains the entire projected prior sequence. A candidate is compatible iff no observed labeled records with equal keys in the same block have opposite labels. Unlabeled records do not impose output constraints, but remain in h. Tables start empty for a new fitted model, histories start empty for each trace. Output functions are block-local; there is no global conjunction/AND of terminal DFA acceptance. This is a fixed-context finite-sample model; failure is not evidence against all possible local regular models.

Compute known-host baseline first for every d, including empty/no-history d=0. Report labeled counts, unique contexts, contradictory contexts, positive/negative counts and minimum unavoidable empirical mistakes sum min(pos,neg). Preserve exact opposing witness record IDs. Global/subnet/unknown/multitarget scopes remain explicit with separate counts and separate diagnostic categories; do not drop them or force them into arbitrary host truth. Host conflicts should be reported both on training and pooled diagnostic data with split attribution; pooled diagnostics cannot fit a training model.

## Inference and independent oracle

Choose exactly min(8, training distinct symbol count) symbols by descending frequency over ALL training events, including unlabeled, with ascending canonical opaque-ID tie-break. Selection must not inspect host truth or outcomes. Freeze S once, shared by every d/method. Evaluate labeled events with current symbol in S. Keep full past global stream and project onto each proposed block BEFORE suffix truncation. Report outside-S counts and global/subnet scopes explicitly; this is bounded selected-alphabet inference, not a full-network recovery claim. Outside-S events are not silently removed from the stored original stream; by declared projection semantics they do not enter histories of blocks contained in S.

Enumerate every unlabeled set partition of S in canonical restricted-growth order (Bell(8)=4140). No graph, merging monotonicity or C015 pruning. Independently compute block compatibility by direct context conflict criterion; complete compatible families, not a status or one candidate, must match. Block subset memoization is allowed only because a block's context calculation depends on that block alone; this is not a monotonicity assumption. Cross-check subset-table method against a direct per-partition replay on bounded synthetic inputs, including a nonmonotone merge example, repeated actions, d=0, empty/unlabeled histories, contradictions, reset and held-out unseen symbols. Master budget ~600s for all active work; no large grid. Enumerate all six d values on one fixed small S if budget permits; otherwise preserve incomplete and avoid uniqueness/nonexistence assertions for unfinished cells.

Compatibility is training-only. Freeze candidate families before opening protected host truth. Afterwards compare unordered induced host partitions on S, conditional on all selected symbols having a unique host scope: exact family inclusion, number of matching partitions and uniqueness/ambiguity. If scope is global/subnet/multihost/unknown or symbol-to-host mapping is nonfunctional, report truth comparison undefined, with counts. Do not choose another S or silently drop difficult symbols. Validation/test evaluate frozen training models only; report known/unseen contexts, coverage and error on known contexts, with no automatic label for unseen contexts. Any tie/output rule must be frozen before GO. A model refit using held-out labels is diagnostic only and separately named.
