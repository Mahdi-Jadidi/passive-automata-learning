# Candidate DP: proof and full-output contract (pre-implementation)

The candidate follows the projection criterion and the V32 subset-DP proof in `../../../2026-11-12/partition_methods_v32/package_a/METHODS_1_2_3_6.md`; paths in this document are descriptive. It is an exact mathematical candidate, not a claim of measured speed. Alphabet order, normalizer, witness serialization, replay, errors, and budget contract are C028's; see `../../../2026-11-11/exact_foundations_v28/implementation/reference.py`. Let m be the alphabet size, n the number of normalized negatives, and R(B) the bitmask of negatives whose projection is absent from positive projections on B. R(B) is defined even when P is empty. Empty subsets are not blocks.

## Counting proof

For a remaining symbol mask S and uncovered-negative mask U, D(S,U)[k] counts partitions of S into k nonempty blocks whose union of rejection masks covers U. The base is D(0,0)=[1], D(0,U≠0)=[0]. For S≠0, let a be its least set bit. For each B⊆S with a∈B add z D(S\B,U\R(B)) to D(S,U), using arbitrary-precision integer coefficients. Each partition has exactly one block containing a; remaining blocks and coverage requirement are unique, including overlapping rejections. Conversely every branch gives one partition. Induction proves the coefficients. Root sum is C, highest nonzero index is k*, and its coefficient O; C=0 has O=0 and undefined optimum. The empty alphabet is handled by the base, with no phantom rejecting block.

## Canonical reconstruction proof

An RGS prefix has q nonempty existing blocks A_0,...,A_(q−1) with disjoint assigned IDs and unassigned suffix S. A completion assigns disjoint subsets of S to each existing block, then partitions the remaining IDs into new blocks. Define G(j,S,U) as the generating polynomial for new blocks when existing blocks j,...,q−1 still need their suffix assignments, and U remains uncovered. For j<q sum G(j+1,S\T,U\R(A_j∪T)) over every T⊆S, including empty T. At j=q use D(S,U). Existing blocks do not multiply by z, and D counts newly introduced blocks. Every full completion corresponds to precisely one sequence of T choices and one partition of the leftover; all blocks are nonempty because every A_j already contains a prefix ID. The full RGS with fixed prefix is unique after canonical first-occurrence labeling. Therefore G(0,S,all-negatives) has a positive coefficient at any exponent iff a compatible completion exists; for optimal witness testing inspect coefficient k*−q. If prefix is empty, directly use D(full,all-negatives).

Build RGSs in lexicographic depth-first order, extending each prefix with labels 0,...,q (only 0 at the first position); descend only when the appropriate exact feasibility query is positive, stop after two complete strings. The query is exact by the bijection above, so pruning removes no qualifying completion, while sorted traversal visits the first two qualifying full RGSs. Existing and new block labels preserve first-occurrence order. A separate traversal for all-compatible and optimal families ensures their orders are independently correct. Empty RGS is handled explicitly. Unlike enumerating all partitions, at most O(m²) queried prefixes per requested pair are needed: at most two successful root-to-leaf paths and their immediate unsuccessful siblings, each having at most m+1 children. Each query may itself require exponential work and memory.

## Cost and resource behavior

The reusable D table has at most 2^(m+n) states and at most O(3^m 2^n) submask transitions, with degree ≤m, bigint and bit-mask costs; R(B) is lazy, with at most 2^m distinct masks computed, each using polynomial input work. A single prefix query with q existing blocks and r suffix IDs has at most O(q 2^(r+n)) memoized G states and O(q 3^r 2^n) transitions, plus D calls, polynomial coefficient and bigint factors. Fresh query caches mean O(m²) such bounds may be incurred, rather than an asserted universal improvement. Hash-based caches, word comparisons, identifier lengths, integer shifts, witnesses and memory are not constant-cost. These bounds are exponential in m and n and can be worse than baseline for some inputs.

All explicit `max_candidates` values, including invalid ones and zero, delegate verbatim to the frozen C028 solve: no reinterpretation as a DP state budget. Unlimited DP catches memory exhaustion, recursion exhaustion, and keyboard interruption as INCOMPLETE with null exact fields; hard termination can produce no output. Invalid input and contradictory labels follow C028. A successful witness is constructed and replayed with frozen reference helpers; caught replay failure returns ERROR, not a result. Python integer arithmetic is exact. This candidate is not a public default.

Biggest overlooked issue: final block assignments must be counted exactly once even though prefix blocks remain open; a naive anchored-subset traversal does not imply lexicographic full-RGS witness order. Feasibility of a partial block cannot be assessed by its present rejection mask, since future IDs can change its projection.
