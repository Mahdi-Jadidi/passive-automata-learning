# V33 candidate: forced-pair graph contraction, full contract

Status: proposed exact algorithm pending independent audit. This is not the V32 subset/coverage DP. It contracts a sound graph and either aggregates its entire coarsening lattice or enumerates that lattice. No claim of universally faster runtime or measured speed is made. Model, input, factor serialization, interrupted/error behavior and ordered witnesses match C028 `implementation/reference.py` (copied byte-for-byte as `baseline_contract.py`); C030's singleton-compatible full-family shortcut is a special case of the component certificate below. The V32 graph proof is `../../../2026-11-12/partition_methods_v32/package_b/DOSSIERS_4_5_9_10.md`. Full C028 requires compatible count C, maximum k*, optimal count O, recommendation and first two compatible and first two optimal RGS witnesses in declared symbol order.

## Construction and proof

Let P,N be normalized finite words and Σ the ordered IDs. For each n and symbol a compute whether π_(Σ\{a})(n) equals some π_(Σ\{a})(p), p∈P. Put a in M_n if equality exists, equivalently n∉R(Σ\{a}). Connect all members of each M_n (a star suffices for the connected components). If a compatible partition has a block B rejecting n, then for every a∈M_n, B contains a: otherwise B⊆Σ\{a}, and monotonicity gives n∉R(B), contradiction. Thus every edge is a must-link, and transitivity proves every compatible partition coarsens the connected-component partition A. This remains sound if no compatible partition exists. Components are ordered by their first position in Σ; unused IDs are included and may be isolated.

A partition of components is in bijection with an original partition coarsening A by taking unions of component members. It preserves the number of blocks. The graph has m vertices and at most Σ_n max(0,|M_n|−1) inserted star edges, and projection preprocessing uses m·|N| tests, each polynomial in total explicit input length L. An inefficient but conservative bound is O(m (|P|+|N|+1) L + m |N| |P| L), including word scanning and collision-safe equality costs, with O(m |N| + L + m) auxiliary storage apart from input and returned witnesses for mandatory lists and temporary projections. This is additional overhead even when it does not shrink the search.

If A itself is compatible, monotonicity under merges makes all its coarsenings compatible; no other compatible partition exists by must-link. Hence C=Bell(q), k*=q, O=1, q=|A|; for q=0 this certificate succeeds only when N is empty. Compute Bell using b₀=1 and b_(n+1)=Σ_{j=0}^n binomial(n,j)b_j, in O(q²) arithmetic operations and big integers of O(log Bell(q)) bits. The first RGS is all zeros; when q≥2, the second lexicographic component RGS is zeros except the last component's first appearance gets label 1. Why: every nonzero RGS first differs from all zeros at some component, and the latest possible first difference yields the lexicographically smallest; a final 1 is the least legal nonzero value. Convert it by assigning each symbol its component's RGS label. The unique optimum assigns a distinct label to each component. When q≤1 there is only one coarsening.

Otherwise enumerate each component partition by its lexicographic RGS and expand it to the symbol RGS, replaying the exact C028 projection criterion. Component first occurrences follow component order, so for any two component RGSs the first differing component has the first differing symbol at its first occurrence; expansion preserves lexicographic ordering and is injective. Therefore the first two accepted expanded RGSs are exactly the canonical first two, and the same holds for the optimal subsequence. Count all compatible partitions and optimal ties without objective pruning. Exhaustion proves counts, optimum, uniqueness and incompatibility. Worst-case Bell(q) tests plus preprocessing, q≤m; if q=m and certificate fails, overhead is strictly extra relative to baseline. There is no speed guarantee. Bell counts and all result counts use arbitrary-precision arithmetic.

For `max_candidates` other than None, delegate the *entire* invocation to the byte-copied baseline. This preserves invalid-budget precedence, prefix inspection semantics, zero budget, contradiction handling, and exact INCOMPLETE behavior; the graph is not constructed. Unlimited mode validates and checks contradiction identically, uses reference witness construction and replay, catches KeyboardInterrupt/MemoryError as INCOMPLETE, and does not return partial claims. Other exceptions are not silently converted. The empty alphabet/empty conjunction, no positive or negative words, repeated labels, epsilon, Unicode opaque IDs and unused IDs follow reference semantics. Finite completion assumes sufficient resources. No solver, state bound, physical uniqueness claim, or original public-code change is involved.

Biggest overlooked issue: existence of must-link edges alone does not prove the component partition compatible; the full-family Bell shortcut is conditional on replaying that partition. A second issue is lexicographic ordering after contraction: the proof relies on components ordered by first appearance, not arbitrary union-find representative IDs.
