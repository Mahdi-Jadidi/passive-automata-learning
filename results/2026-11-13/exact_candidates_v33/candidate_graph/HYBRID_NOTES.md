# Hybrid implementation handoff: exact reusable helpers

Frozen sources must remain unchanged. Entry order: validate/normalize, detect contradiction, C030 singleton certificate, forced-component certificate, DP fallback. All `max_candidates is not None` calls must directly delegate the original input and budget to frozen C028 before any alternative preprocessing.

- C030 `candidate_v1.py::_certified_all(alphabet, positives, negatives)` returns the complete certified full-contract dictionary when the singleton partition passes; returns `None` if it fails. An ERROR dictionary from witness replay is a result, not a signal to continue. This helper uses its own copied C028 routines.
- Graph `candidate.py::_components(alphabet, positives, negatives)` returns `(owners, q)` where each owner is the component index by first appearance. `_expand(owners, tuple(range(q)))` constructs the canonical finest component RGS. Evaluate with `graph._ref._candidate(alphabet, positives, negatives, finest) is not None`. Never call `graph.solve` on certificate failure: it enumerates all component partitions, which is explicitly disallowed in this hybrid.
- On graph certificate success, form all-RGS list from `_expand(owners, (0,)*q)`, adding `_expand(owners, (0,)*(q-1)+(1,))` only for q>1; call `graph._finish(alphabet, positives, negatives, graph._bell(q), q, 1, all_rgs, [finest])`. This reconstructs and replays every required witness and handles q=0 after its compatibility test. Graph `_finish` is NOT by itself a compatibility test; call only after the finest partition succeeds.
- On graph certificate failure, invoke frozen DP `solve(data)` on the original unmodified record. DP will normalize again; that is safe and is part of measured work. This avoids any graph exhaustive fallback. All helper modules are file-path imports with specific source and helper dependency hashes; clearly record runtime dependencies, exceptions at import, and freeze them. C030 and graph functions may return ERROR; don't treat any dictionary as false merely because it is a failure status.
- Wrap unlimited preprocessing in the same KeyboardInterrupt/MemoryError/RecursionError handling used by DP; validation errors and contradiction must have exact C028 status and reason. No assumptions about physical truth, case names or corpus size. A graph cert can succeed with q<m, even though C030 singleton cert failed. The fully empty alphabet needs the empty-partition test and zero-block semantics.

The source of this note is inspection of frozen `candidate_graph/candidate.py`, C030 `candidate_v1.py`, and `candidate_dp/candidate.py`; no hybrid implementation or benchmarking is supplied by this note. Formal guarantees, independent review and timings are required on the final hybrid source hash.
