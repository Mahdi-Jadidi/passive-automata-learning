Thus coefficient k counts exactly k-block completions, even with overlapping rejection masks; summation is C and highest nonzero coefficient yields k* and O.

For a fixed RGS prefix, existing blocks stay open: each suffix element is allocated to at most one pre-existing block by successive disjoint subset choices, or remains for the anchored DP of new blocks. Every finished partition extending the prefix has one such allocation, and every generated allocation yields one extension. Evaluating R only on the completed existing block is necessary. Feasibility tests sum all coefficients, or select k*−q new blocks; traversing valid labels in ascending order with exact feasibility returns first two lexicographic RGSs.
