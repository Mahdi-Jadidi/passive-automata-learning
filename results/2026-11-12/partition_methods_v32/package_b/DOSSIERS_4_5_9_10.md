# Dossiers 4, 5, 9, 10: integer programming, logic, graphs and hypergraphs

Scope: mathematical research only. Status tags concern the stated formulation, not the entire method family. Σ is an explicitly declared ordered finite alphabet of opaque IDs, m=|Σ|, P,N are finite sets of complete words, ε allowed. For B⊆Σ, H(B)={π_B(p):p∈P} and R(B)={n∈N:π_B(n)∉H(B)}. A partition Π is compatible iff ⋃_{B∈Π}R(B)=N: each factor must accept H(B), and conversely finite regular factors H(B) suffice. R is monotone under inclusion. Coarsening preserves compatibility. Let C count all compatible partitions, k* be the maximum number of blocks if C>0, and O count optima. The first witnesses are lexicographically first restricted-growth strings (RGS) in declared alphabet order. Sample uniqueness (C=1), optimal uniqueness (O=1), and physical truth are distinct; none implies physical recovery. Exact output demands replay of H(B), rejection witnesses, and proof of completion. Solver timeout supplies no exact negative or optimality claim. Input length L includes symbol representations and all word occurrences.

Edge conventions for every formulation: empty Σ has exactly the empty partition, compatible iff N=∅; if P∩N≠∅ then C=O=0 and k* undefined. If Σ≠∅ and samples are disjoint, the oneblock partition is compatible. If P=∅ or N=∅ and Σ≠∅ every partition is compatible; k*=m, C=Bell(m), O=1. Unused IDs remain in Σ and must be assigned: their occurrence is not inferred from traces. With P=∅, R(∅)=N, but ∅ is never a block.

## 4. ILP: candidate-block integer program — PROVED

Create x_B∈{0,1} for every nonempty B⊆Σ. For each a require Σ_{B∋a}x_B=1; for each n require Σ_{B:n∈R(B)}x_B≥1; maximize Σ_B x_B. A 0≥1 coverage constraint handles a negative without a candidate, including empty Σ. This is the exact-cover formulation with extra coverage inequalities, expressed as ILP.

The symbol equations select disjoint nonempty blocks whose union is Σ, and conversely each partition gives exactly one assignment. Coverage is exactly the projection criterion; objective equals block count. Thus feasibility and optimum are preserved bijectively. A certified infeasible result proves C=0; a certified optimal result with replay gives k* and one witness. C and O require model counting or complete distinct assignment enumeration; canonical first witnesses require comparing original RGSs or a proved ordered enumeration. An optimal solution and its objective are not those counts. LP relaxation, incomplete column generation, or a restricted subset of candidate blocks may give bounds or feasible solutions only; restricting candidates has no general exactness guarantee.

There are 2^m−1 variables, O(m+|N|) constraints and O((m+|N|)2^m) possible incidence entries. Computing all R(B) takes 2^m polynomial-time projection work in L, plus exponential storage; generic ILP solve can require exponential work. Counts need arbitrary precision. P={ab}, N={ba} refutes a singleton-only candidate restriction: no singleton rejects ba, but {a,b} does. What is the biggest overlooked issue? The exponential representation and the difference between an optimum certificate and the full counting/witness contract.

## 5a. SAT decision — PROVED

Use m labeled slots and Boolean y_{i,k} (1≤i,k≤m), exactly one slot per symbol. Slot k represents B_k={a_i:y_{i,k}}. Let active_k=∨_i y_{i,k}. Build a circuit Eq(w,v,k) for equality of filtered words using the recurrence below; impose for every n, ∨_k(active_k ∧ ∧_{p∈P} ¬Eq(n,p,k)), and impose Σ_k active_k≥t. Empty disjunction/conjunction have their usual false/true values. With m=0, explicitly impose N=∅ and t≤0. For finite m, the slot representation covers every partition, with permutations of labels potentially representing the same partition.

Polynomial projection-equality circuit construction: for words w=w₁…w_r and v=v₁…v_s and membership inputs x_i=y_{id(w_i),k}, z_j=y_{id(v_j),k}, define E(0,0)=true; E(i,0)=E(i−1,0)∧¬x_i and E(0,j)=E(0,j−1)∧¬z_j. For i,j>0 define

 E(i,j)=(¬x_i∧E(i−1,j)) ∨ (x_i∧¬z_j∧E(i,j−1)) ∨ (x_i∧z_j∧[w_i=v_j]∧E(i−1,j−1)).

These cases remove an unselected last symbol, or compare both selected last symbols; induction proves E(i,j) iff the two filtered prefixes are equal. The circuit has O(rs+r+s) gates, including repeated IDs sharing membership inputs; symbol-equality constants are computed from opaque IDs. Standard full gate-equivalence clauses turn each AND/OR/NOT gate into constant-size CNF, with uniquely determined gate values for fixed inputs. Cardinality can be implemented by a polynomial-size counting circuit and comparator. Total circuit and CNF size are polynomial in m and explicit L, though SAT solve is not thereby polynomial. Threshold satisfiability iff a compatible partition with at least t blocks exists: read blocks from the assignment and apply the criterion; conversely assign each block to a distinct slot. Optimization via threshold queries or an optimizing solver gives exact k* only when bounds are proved. P=∅ makes the inner conjunction true, properly rejecting each negative at every active block.

Counting SAT assignments naively overcounts partitions through slot permutations, and one may additionally overcount if a particular CNF conversion permits auxiliary freedom. A canonical RGS slot convention, plus full gate equivalences, gives a unique extension per partition; otherwise use projected model counting/deduplication. Verify canonical ordering explicitly before claiming the first two RGS witnesses. What is the biggest overlooked issue? Equisatisfiability alone does not preserve number or lexicographic order of partitions.

## 5b. MaxSAT — PROVED

Use the SAT construction without the threshold as hard clauses; for each slot add unit soft clause active_k with weight 1. Any hard-satisfying assignment scores the number of nonempty blocks. Thus a certified maximum score and decoded model yield k* and an optimal partition, and hard unsatisfiability yields C=0. Require soft clauses to represent active slots, not individual assigned IDs. Polynomial encoding size follows from 5a, but the solve need not be polynomial. Counting all hard models, all optimal models, and canonical RGSs needs projected enumeration or a canonical injective encoding as above; soft score alone does not provide C or O. Empty Σ and negative samples must use the separate empty-partition condition. What is the biggest overlooked issue? Labeled slots introduce symmetries and the MaxSAT score counts active blocks, not distinct partitions.

## 5c. SMT/OMT — PROVED

Declare integer labels ℓ_i∈[0,m−1], and use the same polynomial equality circuit with membership atom (ℓ_i=k). Assert negative coverage and maximize Σ_k ite(∨_i ℓ_i=k,1,0). Quantifier-free finite-domain integer/Boolean constraints are decidable by expansion, but use an exact solver and certified optimization; solver theory support and machine limits are separate implementation concerns. The assignment-to-partition and objective proofs are those of 5a. Add RGS constraints ℓ_1=0, ℓ_i≤1+max_{j<i}ℓ_j for canonical labels, with the empty case separately defined; then labels biject partitions. Even then one optimum does not count C or O; enumerate distinct labels and replay factors to obtain counts and ordered witnesses, with finite but potentially exponential work. A bounded-state automaton encoding is a different problem and can exclude valid partitions. What is the biggest overlooked issue? An SMT model of labeled blocks is not automatically an injective representation or an exhaustive solution.

## 9. Graph scenarios

### 9.1 Forced pairs and atoms — PROVED, as an exact preprocessing certificate

For distinct a,b draw an edge if some n∈N satisfies n∉R(Σ\{a}) and n∉R(Σ\{b}). By monotonicity any block rejecting that n must contain both a and b. Any compatible partition has a rejecting block for n, so the endpoints share a block. Transitive closure gives forced components ('atoms') that every compatible partition must respect. Compute each test by direct projection in polynomial time; O(m²|N|) candidate pairs with polynomial projection work is a conservative bound. If the partition into these components is compatible, it is the unique finest compatible partition: every compatible partition coarsens it, and every coarsening is compatible. It then gives k*=number of components and O=1; all compatible partitions are precisely its coarsenings, hence C=Bell(number of components), including the empty-component case with its separate compatibility test. RGS witness ordering still needs explicit construction/proof. If the component partition fails, no conclusion follows about infeasibility or unforced pairs: the oneblock partition may fit. The condition is sufficient, not asserted complete for all logically forced pairs. Biggest overlooked issue? Connected components certify exactness only after the component partition itself passes coverage.

### 9.2 Candidate-block conflict and coverage graph — PROVED with side constraints

Make one vertex for every nonempty B⊆Σ, with conflict edges between intersecting blocks. Mark vertex B with all symbols in B and all n∈R(B). Seek a maximum-cardinality independent vertex set that covers every symbol and every negative mark. Nonoverlap plus symbol coverage gives exactly a partition; negative coverage gives compatibility. Conversely every compatible partition gives such an independent set, preserving objective and yielding a bijection. An ordinary maximum independent set without coverage is a different optimization problem: Σ={a}, P=N={ε} has a nonempty conflict-graph independent set but no compatible partition. A plain conflict graph loses negative marks; treating each negative as an ordinary graph edge without a proved gadget is insufficient.

Construction has 2^m−1 vertices and up to O(4^m) pairwise conflict edges, plus projection/mark cost; graph solve and distinct-solution counting may be exponential. It returns exact C, O and first RGSs only if all feasible selected sets are enumerated/duly counted and sorted, with witnesses replayed. Biggest overlooked issue? Pairwise disjointness alone does not encode covering each symbol and negative.

### 9.3 Classical cover, independent set, coloring, clique cover, cut — PROVED restricted reduction; REFUTED-SPECIFIC as a general direct simplification

For any simple G=(V,E), E nonempty, set Σ=V, N={ε}, and P={[u,v]:{u,v}∈E} in any fixed endpoint order. π_B(ε)=ε; π_B([u,v])=ε iff B misses both endpoints. Therefore B rejects ε iff B hits every edge, i.e. is a vertex cover. A partition is compatible iff it contains a vertex-cover block. Let I be a maximum independent set; V\I is a nonempty cover because E≠∅. The partition {V\I} plus singletons for I gives α(G)+1 blocks. Conversely any compatible partition has cover block B; V\B is independent, and all other blocks together contain at most |V\B| blocks. Hence k*=α(G)+1=|V|−τ(G)+1. Input construction is polynomial, including isolates. The nonempty-edge assumption is essential: with E=∅, P=∅ and the formula α+1 exceeds m. The earlier v27 proof uses a different equivalent reduction; this is the requested new variant.

This establishes NP-hardness of general optimum and threshold (hardness survives E≠∅ by adding a disjoint edge), not impossibility of exact solution. On bipartite G, maximum matching gives minimum cover and therefore k* in polynomial time for this restricted sample family; construct the cover plus complement singletons. It does not establish polynomial C, O, or first witnesses: an optimum may have more than one rejecting block, so naively counting minimum covers can overcount. No complexity claim about those counts is made.

General samples require one block to reject each negative against all positives, which may involve order and multiple symbols; the graph above is a special construction, not a universal ordinary vertex-cover formula. For example P={ab}, N={ba}: singleton blocks do not reject, while {a,b} does, although the two symbols co-occurring is not itself a proof of a pairwise must-link in every different sample. Coloring/partition into cliques, min-cut and bipartite matching solve their own defined objectives; a transformation must prove both directions, objective preservation and size bounds. Their failure under a proposed direct graph is not a rejection of all graph gadgets. A cut can encode some pairwise energies, but no universal minimum-cut reduction is proved here. Biggest overlooked issue? Polynomial optimum on the bipartite restricted family does not imply polynomial counting or general-instance optimization.

### 9.4 Auxiliary-node encoding — PROVED polynomial decision representation; OPEN as a standard unweighted graph objective

Use the explicit polynomial circuit in 5a with threshold t. Convert every gate equivalence to constant-size CNF, retaining the y variables, and include polynomial exactly-one and cardinality circuits. Each clause gives three-literal-or-shorter clauses after bounded fan-in gate conversion. The classic clause-occurrence graph has one vertex per literal occurrence, conflicts between opposite literals from different clauses, and all pairs within a clause; ask for an independent set of size equal to the number of clauses. A satisfying assignment chooses one true literal per clause; conversely such an independent set picks a consistent literal per clause, extendable to a satisfying assignment. Thus decision is polynomially reduced, including actual projection equality, not merely asserted through an unspecified gadget. Graph construction is polynomial in circuit/CNF size; subsequent independent-set solving can be exponential. Decode y into a partition, replay the criterion, and binary-search t for k*. This is a polynomial number of polynomial-size graph instances, not one proved objective-preserving graph whose independent-set optimum itself equals k*. Multiple literal choices and labeled slots overcount partitions. Finding an appropriate parsimonious or single-instance standard unweighted graph optimization encoding is OPEN here; no impossibility is claimed. Biggest overlooked issue? Polynomial reduction size does not mean polynomial graph optimization, or parsimonious counting.

## 10. Minimal rejecting hypergraph — PROVED

For each n define F_n={T⊆Σ: T≠∅, n∈R(T), and no nonempty proper subset rejects n}. Hyperedges are subsets of alphabet IDs and are indexed by negative: the empty family means no allowable block rejects that negative. For every nonempty B, n∈R(B) iff B contains some T∈F_n. Forward: among the finite nonempty rejecting subsets of B choose an inclusion-minimal one. Reverse: monotonicity. Therefore choose a partition maximizing blocks, subject for each n to some block containing a hyperedge from F_n. Each partition is represented exactly once at the partition level and the objective is preserved. This handles P=∅: if m>0, all singletons are minimal nonempty edges for every n, even though R(∅)=N; for m=0 there are no such edges, and the empty partition fits iff N=∅. If a negative equals a positive then F_n is empty, so no partition is feasible. N=∅ gives no hyperedge requirements. Unused IDs remain vertices.

Enumerating F_n by testing all 2^m−1 nonempty subsets and their immediate nonempty deletions is exact by monotonicity, with exponential projection cost and potentially exponential output. For each n, F_n is an antichain; no polynomial output bound is asserted. Explicit hyperedge containment constraints can still require exponential combinatorial search. A heuristic or truncated hyperedge list can miss feasible partitions; a single graph of pairwise co-occurrence loses higher-order requirements. Example P={abc}, N={cba}: each singleton projection agrees, while each two-symbol restriction reverses order, so minimal rejecting sets are pairs; other instances can have genuinely larger minimal sets. To obtain C, O and first RGSs enumerate/count distinct partitions, not choices of which contained hyperedge certifies them: several hyperedges can witness one block and one partition. Biggest overlooked issue? Minimality is over nonempty subsets, and hyperedge witness multiplicity must not be counted as partition multiplicity.
