# C004-QOP001 — bounded local-language opposition

Status: independently reasoned candidate proof, source prepared, NO execution during Stage1 timing. Parent: S001 projection extraction/certificate routines and general cap-q feasibility theorem. No novelty claim. Provider: bounded_certificate_v1.py; it imports frozen singleton_solver_v1.py only for validation, projection construction, graph certificate and deadline helpers. It does not call singleton solve, count-equality tests or threshold-one opposition.

Assume known k nonempty disjoint alphabet blocks and each factor language has cardinality at most q>=1. The empty language is allowed. Positives are complete words and labels exact. For any two symbols a,b in the same block B, the set of positive {a,b} projections is an image of the set of positive B projections under erasing projection. Its cardinality therefore cannot exceed the cardinality of the local language, at most q. Hence MORE THAN q distinct positive binary projections force different owners. Exactly q different projections do not force different owners. For q=2, positives abc,bac can have a,b together with local language {ab,ba}; ordinary threshold-one singleton opposition is invalid here.

Unary strengthening: if the positive counts of any one letter take more than q different values, every block containing that letter needs more than q distinct local words. Thus the entire at-most-q class is infeasible for any partition. Equal counts are not required; unlike S001, merely different counts are not rejected.

Construct a graph with an edge for every pair whose projection set exceeds q. Every bounded-language-compatible partition is a proper surjective k-coloring, but the converse need not hold: the full block can have more than q positive projections even when all pair tests stay at most q. Thus q-opposition is only a necessary graph relaxation. If the graph is complete k-partite, its unique k-coloring fixes the sole possible candidate partition. For k=2 a connected bipartite graph is sufficient to fix that candidate too. The generic graph proof from S001 is model-independent. Directly form every candidate block's full positive-projection set and reject it if any has more than q words. Then check every negative has an unseen block projection. A successful check certifies the unique compatible bounded-language partition; a failed cap/negative check proves full-class infeasibility because every compatible partition would have been that same forced graph coloring. No graph certificate means insufficient_coverage, not infeasibility.

The model, even with q=1, is at-most-q finite languages. With a nonempty positive set its minimum factor language is the observed projection set. With an empty positive set empty local languages are permitted and all negative words are rejected by those languages; this certificate provider deliberately returns insufficient_coverage rather than enumerating the compatible partitions. It does not adopt singleton-exactly-one empty-positive semantics.

## Prepared constructive q=2 coverage family

Use k>=2 equal-sized nonempty blocks, listed in a fixed internal order. For each block i let ui be two repetitions of its symbol list. The first positive concatenates u1,...,uk; the second concatenates them in reverse block order. The third interleaves all ui in lockstep round-robin, preserving each ui internally. For any cross-block pair a,b, the first two projections are aa bb and bb aa, while lockstep yields a b a b or b a b a according to factor order. These are three distinct words, exceeding q=2. For any within-block pair all three projections agree, since the local word is ui each time. Thus the first three positives produce exactly the complete k-partite q-opposition graph although all factor words are still singleton so far.

Add a fourth positive concatenating vi=ui followed by the first symbol of block i. Each block now has exactly the two local words {ui,vi}; it is a genuine two-word factor family. Cross-block q-opposition edges persist. Within-block pair projection sets have at most two values, so no false internal edge is added. The forced full-block cap check succeeds with q=2. Because positive length need not be uniform, record all lengths; lengths are respectively 2m,2m,2m,2m+k in the basic construction. To scale, use r>=2 repeats instead of two: concatenation/reverse/lockstep still give distinct cross projections; fourth word length increases by k. The traces remain deterministic coverage witnesses rather than an arbitrary passive distribution.

Proposed explicit smallest nontrivial example: blocks ab|cd, ui=abab and cdcd; positives ababcdcd,cdcdabab,acbdacbd,ababacdcdc. Local languages should be {abab,ababa} and {cdcd,cdcdc}. Note the fourth positive is concatenation ababa + cdcdc. Negatives can include epsilon or a word violating the full-block local set. This spelling must be checked by a captured harness before treating it as executed evidence.

## Complexity and evidence

Each binary-projection dictionary retains at most q+1 distinct values, with the first positive index for each. Once a pair has q+1 values it is an edge and further values are not retained. This caps retained set cardinality; strings themselves still have length. Reuse of S001 bucket extraction costs O(mL+m²) per word and retains one temporary all-pairs projection tuple, plus stored witness values. For a maximum trace length L, coarse retained projection memory is O((q+1)*mL + m²) plus output/witness bookkeeping. q+1 entry count alone is not a constant-byte memory claim. Generic complete-multipartite certificate sorting has the separate O(m² log m) upper bound noted in COMPLEXITY_SCOPE_S001_NOTE_001.md.

Full candidate positive sets are also checked directly and stop on q+1 values if infeasible; successful results materialize all <=q words per block and all negative witnesses. No truncation is used.
