# C004 S001 — singleton opposition, Stage 1

Scientific status: proved sufficient condition; execution status: awaiting captured smoke and independent audit. Parent: C003 S001, immutable cycle f7ae918a. No novelty claim. This proof concerns exactly k nonempty disjoint alphabet blocks and singleton local word languages, including the local word epsilon. Positive sample must be nonempty (the set may contain epsilon).

Let r be a reference positive. If any positive has a different count of any letter, no singleton product fits. Otherwise put an opposition edge ab exactly when some positive has a different {a,b} projection from r. If a,b belonged to one factor their projections would agree, so every compatible partition is a proper surjective k-coloring.

Conversely each independent block B has the same projection in every positive. To prove this, label each occurrence of each symbol by its occurrence rank. Counts agree. Every pair of occurrences of different symbols in B has the same relative order because its binary projection agrees; same-symbol occurrence order also agrees. Thus all occurrence pairs have the same order, and the whole B word agrees. This also handles unary or empty projected blocks. Hence positive-compatible partitions are EXACTLY the proper surjective k-colorings of opposition. Negative n is rejected exactly when some block projection differs from its unique reference word. The implementation checks all full projections rather than relying only on this lemma.

If opposition is complete k-partite with k nonempty parts, those parts give its unique surjective k-coloring, unordered. Pick one representative from every part: these form a k-clique and must use k colors. Every other vertex is adjacent to representatives of all other parts, leaving precisely its own part's color. This certificate works for k=1,2,3,4,6,8 and all alphabet sizes; no length bound is needed. Code computes complement connected components then explicitly checks every pair for the complete-multipartite property. Complement connectedness by itself is not used as a certificate.

For k=2, connected bipartite opposition suffices: the root color forces each vertex's color by path parity; both parts are nonempty. This assertion is NOT extended to k>=3. For example, positives abcd,bacd,acbd,abdc produce path ab-bc-cd. It is connected but admits three surjective 3-color partitions: the doubled block is ac,ad,or bd. Remaining vertices are singleton blocks. A captured independent enumeration is supplied separately.

Constructive sufficient positive coverage: let B1,...,Bk partition the known alphabet and let ui be a word over Bi containing every symbol of Bi at least once. Positives u1...uk and uk...u1 have equal local words. All cross-block symbol pairs reverse their block order and therefore have different binary projections. Same-block projections agree. The opposition graph is exactly complete k-partite. The condition that each symbol occurs is material: an absent symbol has no such opposition evidence. Extra compatible positives preserve the certificate.

All-pair extraction: build incidence lists for each symbol containing its m-1 unordered pairs. Scan a word once; append each letter to each incident pair bucket. The bucket is exactly the order-preserving binary projection by construction. Each letter is appended m-1 times, so time is O(mL+m²), memory O(mL+m²) per word, instead of O(m²L) repeated whole-word scans. Reference and current buckets coexist; positive words are processed serially. Joining and comparing buckets also costs O(mL+m²). Validation and full candidate projection are O(total input length + sample_count*k). Graph serialization can cost O(m²); local words and negative witnesses can cost O(total input length). No output is silently truncated.

If the supported unique coloring certificate fails, Stage 1 returns insufficient_coverage. That does not assert infeasibility or nonuniqueness. If a certificate succeeds but a negative is accepted, its unique positive candidate is eliminated, proving infeasibility within this class. No result certifies uniqueness in general regular-factor models. No-positive singleton semantics are deliberately unresolved.

Deadline checks occur throughout input scans, bucket construction, pair comparisons, graph traversal and candidate checks. An incomplete result never asserts exhaustion or uniqueness. Python joining of an individual bucket and JSON serialization are bounded operations outside fine-grained interrupt checks; hard capture timeout is also required.
