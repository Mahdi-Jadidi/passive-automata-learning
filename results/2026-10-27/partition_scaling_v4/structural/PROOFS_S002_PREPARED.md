## Unknown k: a combined certificate under singleton assumptions

Let p=xaby be positive and n=xbay negative, where a!=b. In any disjoint-alphabet product, if a and b lie in different factors then every local projection of p and n is equal. Since one is accepted and one rejected, a and b must belong to the same factor. This must-link implication does not require singleton local languages. Its transitive closure gives forced-together components. Keep a concrete p,n,swap-position witness for every must-link edge.

Under singleton assumptions, combine these components with positive opposition edges. If an opposition edge has both endpoints in one component the singleton class is infeasible. Otherwise form the quotient opposition graph. If it is a clique on c components, all components must be different factors while every component must stay intact. Thus the only compatible alphabet partition, for ANY number of nonempty blocks, consists exactly of these c components. Direct positive projections and negative rejection must still be checked before returning a model. This yields a sufficient unknown-k singleton certificate and infers k=c. The clique condition concerns quotient components, not necessarily all symbol-level cross pairs.

Prepared example: alphabet abcd; positives abcd,cdab; negatives bacd,abdc. The two negatives force ab and cd together, while positive block reversal opposes all cross-block pairs. The unique variable-k singleton partition is {ab},{cd}. This is proposed for captured verification only after go.

Positives ab,ba and no negatives have opposition K2; on alphabet abc, the isolated c can join a, join b, or form a third block. Thus minimum k=2 does not identify the true k or a unique partition. Naive generalization 3 fails: uniqueness in the singleton class does not identify unknown-k arbitrary regular factors. For any finite consistent sample a one-factor model with local language equal to the finite positive set fits; with no positives use the empty regular language. Therefore generic unknown-k regular identification needs an extra criterion or assumptions.
