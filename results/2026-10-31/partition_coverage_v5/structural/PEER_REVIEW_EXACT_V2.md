# Peer review of exact provider v2 — structural worker

Reviewed source `general/known_k_qexact_v2.py`, SHA256 9f08dd645e7fcccbe8ea8022c758b7cf3277a5f01b6533fb9c1ad0cf08b6c84d, and `EXACT_SEARCH_QOPPOSITION_PROOF_V1.md`. This is a read-only proof/source review, not an independent oracle execution.

Disposition: mathematical pruning and full-set enumeration are sound under declared known-k disjoint-alphabet complete-label semantics, subject to independent audit. No new correctness blocker found in v2.

* Binary opposition uses strictly more than q exact projected STRINGS. Unary projection count >q is globally impossible, including empty string counts for absent symbols. At q=None no opposition is inferred. No threshold-one shortcut leaks into bounded q>1.
* Positive projection sets on partial blocks are monotone in cardinality under extension: erasing back gives an onto map to the former sets. Thus direct partial-cap pruning cannot lose a feasible complete partition. It remains active when pair constraints are disabled, as required for the baseline.
* Must-links use adjacent-swap and insertion-rescue evidence. Hashes select candidates only; exact string comparisons guard collisions. The insertion-rescue check requires a positive base obtained by deleting a from negative, and a positive rescue formed by insertion of a distinct b next to a. If a,b are separated, the factor holding a sees its negative projection in the rescue while other factors see it in the base. Therefore separated ownership would force acceptance. The component closure is sound.
* A pair cannot-link inside one must-link component is a true model contradiction. Fewer must-link components than k also makes exactly k nonempty blocks impossible.
* Restricted-growth component enumeration starts at (0,), extends only to an existing color or the next fresh color, and finally requires exactly k colors. This enumerates every unordered component partition once. Cannot-link filtering only eliminates conflicts between already assigned components. All missing alphabet symbols retain singleton atoms unless genuine evidence links them.
* Full leaves directly materialize all positive block projection sets and check EVERY negative. The partial cap test runs before leaf validation, so `_direct` need not separately recheck q. Returned witness languages are sufficient finite regular languages for q=None as well as capped languages when q is finite. Empty positives yield empty local languages; every negative is rejected, matching the adopted at-most-q convention.
* Exhaustion is correct: an unexpanded stack always prevents complete=true; a requested solution limit only certifies enumeration completion if no stack remains. One solution with pending work gives uniqueness unknown; two solutions prove ambiguity even when not exhausted. Interrupted current nodes were popped but `interrupted` prevents accidental exhaustion. Immediate interruption returns false completeness and unknown uniqueness.

No historical source overwritten.

Operational limitations: input validation and some metadata construction do not periodically check deadline, so cooperative cutoff is not a hard wall limit. Pair sets retain all projections rather than q+1 witnesses and perform direct projection scans for all pairs; long-trace cost can dominate. None is a mathematical false-pruning issue. `math.isfinite` on astronomically large integer deadlines could raise OverflowError rather than ValueError; ordinary float deadlines satisfy the contract. Structural provider accepts k=1 but exact/common public domain starts k>=2; compare only intersection.
