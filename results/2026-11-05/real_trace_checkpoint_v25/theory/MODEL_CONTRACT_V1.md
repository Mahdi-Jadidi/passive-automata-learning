# C025 full-history selected-output contract v1

Status: mathematical proof and local record/schema assessment; no new experiment, source execution, novelty or performance claim. This reintegrates C017 full-history T1/T2/coarsening, with explicit contrast to C016/C024. Public C024 is unchanged. C017 drafts were unrun at their recorded pause; the manager has now lifted that pause only for this bounded assessment.

## Model
A finite nonempty alphabet Σ consists of atomic complete event types, not characters in an action name. A partition Π assigns each type to exactly one nonempty block. Every block has a deterministic finite-state Mealy transducer with one common fixed initial state across traces under a declared reset convention. On event a, only its owning block consumes a and updates state; other blocks do not update. Its transition output is the observed global output for that event. This is selected last-event output, not conjunction of all components’ acceptance states. Outputs and previous outcomes are not input symbols or feedback; stochasticity and autonomous/unobserved local updates are excluded.

Observations are finite pairs (h,y), where h∈Σ+ is the complete input history from the declared start through the labelled event and y is a known output. Each trace yields such pairs at known-labelled event endpoints. The proposed binary criterion is:

C(B): there do not exist opposite-labelled observations (p,yp),(n,yn) such that last(p),last(n)∈B and π_B(p)=π_B(n).

A partition is compatible iff every block satisfies C(B). Only pairs whose current/last event is owned by B impose outputs on B. For a finite multiclass output set replace opposite labels with unequal labels. A declared Unknown/missing observation imposes no output constraint, while its input event remains in subsequent histories. Treating UNKNOWN as a genuine output class is a different valid versioned target, not the same missing-label policy.

## Necessary and sufficient finite-state realization
Necessity: if last(h)∈B, π_B(h) is nonempty and is exactly B’s complete input history through the current event. Starting from its fixed initial state, a deterministic Mealy machine produces one last-transition output on that word. Equal such words cannot require unequal outputs. Therefore every compatible partition satisfies C(B).

Sufficiency: for each B collect all prefixes of all observed projected histories, including histories whose current event lies elsewhere and unknown-labelled events. Construct a trie with root epsilon and one state per distinct prefix. At every observed constraint with local word ua (a∈B), assign output y to trie transition (u,a). Equal full local words are exactly equal (u,a) pairs; C(B) guarantees assignments agree. All prefix transitions exist, and unlabelled transition outputs can be chosen arbitrarily from a nonempty output alphabet. Add an absorbing fallback state and send unseen trie extensions to it with arbitrary outputs; make its transitions total. The resulting finite deterministic transducer realizes every known output. The asynchronous product of these independent transducers realizes all observations because only the active owner’s output is selected. This proves existence, not minimal state count, prediction outside constraints, or physical correctness.

Finite upper bound: at most 2 plus the sum of projected-history lengths per block states using all prefixes and fallback (shared prefixes reduce it). Building from full trace streams avoids repeatedly copying every global prefix; naive materialized-history input can be quadratic. No running-time improvement is established here.

## Coarsening and unknown K
If a fine partition is compatible and C merges some blocks, suppose a conflict occurred on C: equal π_C(p)=π_C(n) with both last events in C and unequal outputs. Equality of nonempty projected words implies last(p)=last(n)=a. Hence both last events belong to the SAME fine block B owning a. Project the equality further to B to obtain a forbidden fine conflict. Contradiction. Coarsening therefore preserves compatibility for full input history. Equivalently, a merged transducer can simulate the finite product of its constituent local machines and select the old owner of the current symbol.

Oneblock is compatible iff no identical complete global history has different known outputs. Unlike C024’s valid disjoint-label convention, an observation table may contain such contradictions; if it does, EVERY partition is incompatible. Do not silently deduplicate unequal labels. Otherwise oneblock exists. A nontrivial compatible partition exists iff a compatible bipartition exists, by grouping blocks. Therefore no-K unique can only mean oneblock; finding a split plus oneblock proves ambiguity. This does not recover a hidden number of components. K may be supplied only as an external assumption; host count is not automatically the model’s factor count.

C(B) is NOT upward-monotone over arbitrary candidate blocks: merging compatible BLOCKS preserves a compatible partition, but adjoining an independently inadmissible block can introduce its conflicts. C024 reject-mask envelopes and swap atoms do not transfer. Full-history coarsening also does not hold for fixed finite suffix depth; see COUNTEREXAMPLES_V1.md.

## Bounded-memory experimental extension and assumptions ladder
The proposed depth set is fixed at 0,1,2,4,8,full. At finite depth d the key is (last d PRIOR selected local event IDs,current ID), retaining true short-history length; outcomes never enter the key. C017 proves exact agreement and finite Mealy realization at each depth, but coarsening fails for every finite d≥1 (CE4). No C024 bipartition shortcut, swap must-link or envelope is admissible there. Depth0 is current-type constancy: partition cannot resolve a type’s conflicting labels.

For m≤8, exact-cover recursion may choose a FINAL block containing the least remaining symbol, check its consistency and recurse on the complement; every partition occurs once. Stop after two witnesses for ambiguity. Unique/incompatible require full completion; optional K count bounds are only externally trusted. Do not prune a growing partial RGS block just because its current context table conflicts.

Freeze top8 selection using training-only event frequency and a deterministic ID tie-break. For B within this subset, context is projection of the full ordered input stream onto B; unselected events do not enter that local context and their current-event labels are excluded. This loss of same-host causal actions is an explicit abstraction boundary, even when their labels are known. Unknown-labelled SELECTED events still enter context. Reset context only at declared trace starts. Preserve counts of selected/unselected events, known/unknown/excluded labels, and empty projected traces. Report known-host full-alphabet baseline separately from restricted-host subset membership; the subset baseline cannot replace the full one.

Return invalid_input for malformed schema, undeclared IDs, illegal labels/partition/depth/K or absent required provenance fields under the frozen API; validate every record before reporting a completed result. Return unresolved for deadline/resource interruption, with complete=false and no exhausted claim. Deterministic same-key unequal known outputs are valid-data model incompatibility, not malformed input. Serialize source references and metrics safely without leaking protected host/TrueState fields into inferencer inputs. Independently test the unrun C017 evaluator before reusing it.

Advisor assumptions ladder: (1) verified raw event/status alignment and simulator provenance; (2) explicit strict-vs-artifact Unknown policy and start/reset convention; (3) atomic observed-target qualification with opaque inference IDs; (4) full-alphabet known-host consistency diagnostic; (5) training-selected bounded alphabet and fixed depth, with coverage and restricted-host family membership; (6) full-history version-space comparison. Each rung changes or tests assumptions; none alone establishes physical device recovery. Larger depth relaxes context agreement and can increase ambiguity. Heldout unconstrained contexts require abstention or a separately specified prediction rule.
