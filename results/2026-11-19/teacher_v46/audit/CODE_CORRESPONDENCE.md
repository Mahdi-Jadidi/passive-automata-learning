# V46 first-principles review

The algorithm under review is the frozen V45 implementation at the checkpoint identified in the experiment environment record. The archived V46 review draft compared singleton feasibility and cut predicates, and was preparatory. This run uses the read-only V45 kernel tests, a separate small partition oracle, an injected interruption and the V46 adversarial certificate replay. Review and drafting included AI-assisted Terra contributions.

| Proof obligation | Executable correspondence | Evidence and boundary |
|---|---|---|

The code review distinguishes the theorem from the tested software. Its finite evidence does not establish formal correctness of Python, the solver or the shared encoder. No original executable of the supplied manuscript was provided. The conformance claim is based on source comparison with its specified algorithm, restricted to the implemented decision interface.

The first new opaque-ID batch used a two-second solver cap. The sample with positive singleton words `[opaque log α]` and `[b]` and negative ε exceeded this cap. The original driver called the consumer on that incomplete envelope, and the consumer refused the envelope's null certificate. This is a resource outcome. The initial results are retained in `foundations_initial_2s.json`. The replay uses a 60-second solver cap, logs both caps per row and calls the consumer for completed outcomes only.
