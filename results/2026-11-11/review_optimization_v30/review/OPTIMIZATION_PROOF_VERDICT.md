Boundaries: m=0/N=[ε] fails singleton certificate; m=0/N=[] returns the one empty partition; m=1 has one partition; m=2 has first RGS 00 and 01. Positive/negative duplicate normalization and opaque IDs must be tested, along with contradictory samples, late invalid fields, exact budget boundaries, stale-cache prevention, and eviction past 256. This proof does not establish novelty or generic polynomial complexity; the Bell shortcut is a special case, and cache lookup or prechecking can add overhead. ## Exact integers and bounded cache: complexity boundary

Bell(m) is returned as an exact arbitrary-precision Python integer; O(m²) in the proposal counts arithmetic operations, not constant-time bit operations or character output. Python's configurable integer-to-decimal conversion digit limit may cause JSON/repr conversion of a very large integer to fail even when the pure solver returned the correct integer. The baseline is a pure Python result API; no unconditional JSON wire-serialization guarantee follows. This limitation must be disclosed rather than rounded, truncated, or silently labeled successful serialization. For B, LRU eviction can trigger arbitrarily repeated block recomputation throughout an exhaustive run; a bound assuming every distinct block is evaluated once is unsupported. These qualifications do not alter the proposal proof.
