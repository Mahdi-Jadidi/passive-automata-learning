The count of optimal partitions and the count of all compatible partitions answer different questions.

```text
GENERATE-RGS(m):                  # lexicographic order; m is finite
    if m = 0:
        yield []
    else:
        yield from EXTEND([0], 0, m)

EXTEND(s, largest, m):
    if length(s) = m:
        yield s
    else:
        for x = 0, 1, ..., largest + 1:
            yield from EXTEND(s followed by x, max(largest, x), m)

CHECK-AND-WITNESS(Sigma, P, N, s):
    blocks = nonempty label preimages of s in Sigma order
    for each block B in blocks:
        H[B] = set of projections of every p in P onto B
    rejecting_block = empty map
    for each negative n in N:
        find a block B such that projection(n, B) is not in H[B]
        if no such B exists: return FAIL
        rejecting_block[n] = the first such B in block-label order
    return (s, blocks, H, rejecting_block)

EXACT(record):
    validate full input schema and symbol membership
    if malformed: return INVALID_INPUT with mathematical fields null
    let Sigma, P, N = record.alphabet, record.positive, record.negative
    deduplicate repeated words separately within P and N
    if any word appears in both P and N:
        return completed INCOMPATIBLE with counts 0 and no witnesses

    compatible_count = 0                 # arbitrary precision
    optimal_count = 0                     # arbitrary precision
    best = none
    compatible_witnesses = []
    optimal_witnesses = []

    for each s generated by GENERATE-RGS(length(Sigma)):
        w = CHECK-AND-WITNESS(Sigma, P, N, s)
        if w = FAIL: continue
        compatible_count += 1
        if length(compatible_witnesses) < 2:
            append w to compatible_witnesses
        k = number of blocks of w
        if best is none or k > best:
            best = k
            optimal_count = 1
            optimal_witnesses = [w]
        else if k = best:
            optimal_count += 1
            if length(optimal_witnesses) < 2:
                append w to optimal_witnesses

    if compatible_count = 0:
        return completed INCOMPATIBLE with counts 0 and no witnesses
    replay and verify retained factor and negative-rejection witnesses
    if witness verification fails: return ERROR with mathematical fields null
    status = UNIQUE_COMPATIBLE if compatible_count = 1 else AMBIGUOUS
    return status, compatible_count, best, optimal_count,
           optimal_unique = (optimal_count = 1),
           recommendation = optimal_witnesses[0],
           compatible_witnesses, optimal_witnesses
```

Generation and checking must complete before exact counts, optimum, or uniqueness are returned. An interruption at any stage yields INCOMPLETE and null mathematical fields; witness-verification failure yields ERROR rather than a mathematical conclusion. A completed contradiction check can safely return INCOMPATIBLE early. These outcomes do not authorize silently dropping words, capping the alphabet, or returning a partial count. Empty Sigma generates exactly one RGS and no blocks; the check passes exactly when N is empty. Outputs of all cases should follow the complete field conventions in SPEC.md.
