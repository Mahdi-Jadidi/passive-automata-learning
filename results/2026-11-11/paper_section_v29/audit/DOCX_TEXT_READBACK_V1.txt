Exact sample-compatible partitioning by exhaustive enumerationModel and problemLet Σ = (a₁,…,aₘ) be an ordered finite alphabet of pairwise distinct atomic symbol identifiers. A word is a finite sequence of these identifiers, including the empty word ε. Let P,N ⊆ Σ* be finite positive and negative full-word observations. For B ⊆ Σ, π_B deletes every symbol outside B and preserves the order and multiplicity of the remainder. A partition Π of Σ has nonempty, pairwise disjoint blocks whose union is Σ. For each B ∈ Π, a regular language F_B ⊆ B* is an independent local factor. The induced global language isL(Π, (FB)) = {w ∈ Σ* : ∀ B ∈ Π, πB(w) ∈ FB}.A partition is sample-compatible if some collection of regular factors accepts all P and rejects all N. There is no supplied number K of factors, bound on factor states, hidden target automaton, or owner label. Finite observations leave all unobserved words unconstrained. For Σ = ∅ we adopt the unique empty partition and the convention that the conjunction of zero factors is true; consequently its language is {ε}. These are Boolean full-word labels, not prefix-closed, noisy, timing, or general log semantics.The optimization objective ismax { |Π| : Π is sample-compatible }.When the feasible set is nonempty, a canonical optimum is the lexicographically least restricted-growth string (RGS) among its maximizers, using the supplied alphabet order. This maximizes the number of sample-compatible blocks; it does not identify physical owners or the true number of devices. The method additionally computes the number of all compatible partitions and the number of optimal partitions, both exactly. These counts are over partitions, not machines or probabilities.In the reference interface, the input record has exactly alphabet, positive, and negative keys. Identifiers are distinct nonempty strings; words are arrays of whole identifiers and ε is []. Identifiers may contain multiple characters, Unicode, punctuation, or one another; equality is exact with no tokenization or normalization. Word duplicates within each label are removed in first-occurrence order. Unknown IDs, wrong types, duplicate alphabet IDs, empty IDs, and missing or extra fields are malformed. The exact encoding prevents ambiguity between, for example, ["ab", "c"] and ["a", "bc"].Projection characterization and constructive witnessesFor B ⊆ Σ define H_B = {π_B(p) : p ∈ P}.Theorem 1 (compatibility criterion). A partition Π is sample-compatible if and only if∀ n ∈ N  ∃ B ∈ Π  ∀ p ∈ P : πB(n) ≠ πB(p).       (1)Proof. If Π is realized by consistent factors, every factor F_B must accept π_B(p) for every p ∈ P. Every negative n must be rejected by at least one factor, so that single block's projection differs from every member of H_B. Conversely choose F_B = H_B for every block. These languages are finite and therefore regular, including when H_B is empty. Every positive is accepted by all factors, while (1) supplies a rejecting factor for each negative. For the empty partition, (1) holds exactly when N is empty, consistent with the empty conjunction. ∎The order of quantifiers in (1) is essential. With Σ = {a,b}, P = {a,b}, N = {ab}, each positive differs from ab on some singleton, but neither singleton separates ab from both positives. Thus {a}|{b} fails while {a,b} fits.The constructed factor list H_B and one rejecting block per negative form a finite certificate. For the concrete representation, blocks are in RGS-label order; factors[i] lists the distinct projected positive words in first-occurrence order; negative_rejected_by[j] is the zero-based first rejecting block for the j-th deduplicated negative in first-occurrence order. Hence repeating a raw negative cannot change the proof obligation. The conceptual witness operation serializes each set H_B using this first-occurrence order. These factor languages are a consistent realization, not a claim that they are the actual unknown factors.Enumeration and algorithmFor m>0, an RGS s = (s₁,…,sₘ) satisfies s₁=0 and 0≤sᵢ≤1+max(s₁,…,sᵢ₋₁) for i>1. Labels name blocks in order of first occurrence. The empty RGS represents the unique empty partition when m=0. Each partition has exactly one such string: label its blocks by first occurrence. Conversely, the growth rule guarantees that the nonempty label preimages form a partition and first appearances are ordered. These constructions are inverses. Generating the permitted next labels in ascending order therefore enumerates all partitions exactly once in lexicographic RGS order.The following conceptual recursive generator is extensionally equivalent to the frozen implementation's iterative rightmost-increment/zero-suffix generator. The equivalence is explicit: for any nonfinal RGS, the iterative generator chooses the rightmost position that can increase without changing its prefix, increases it by one, and replaces its suffix by zeros. This is the lexicographically least valid RGS greater than the current one: no later position can increase, a smaller increment is impossible, and the all-zero suffix is the least legal completion. If no such position exists, the string is last. Since both generators start at all zeros and repeatedly follow the same lexicographic succession, their outputs coincide. The implementation stores selected RGS strings and constructs witnesses only after enumeration. On fixed normalized P and N, witness construction is deterministic and depends only on the selected RGS and those data, so deferring it yields exactly the same witnesses as eager construction. INCOMPATIBLE has zero counts and no recommendation; INVALID_INPUT, ERROR, and INCOMPLETE have null mathematical result fields. A force-killed process need not return an output at all.Termination and cost. There are Bell(m) set partitions (Bell(0)=1). On any non-contradictory run that completes exhaustive enumeration, the number of candidate evaluations is exactly Bell(m); validation and completed contradiction detection may return earlier. Each candidate's projection checks and witness construction use polynomial work in the explicit finite input size under ordinary exact string and array operations. Thus a conservative total bound is Bell(m) times a polynomial in input size, including symbol-ID encoding and arbitrary-precision count operations; no polynomial bound in variable m is claimed. The retained witness data are polynomial in the explicit input size, while exact counts require O(log Bell(m)) bits and the enumerator keeps a finite RGS state; this says nothing about a practical time or memory budget. Completion on every finite input is a mathematical statement under sufficient resources, not a wall-clock guarantee.For a valid nonempty alphabet, oneblock fits iff P∩N is empty. For the empty alphabet, the sole empty partition fits iff N is empty; its completed counts are C=O=1 and best=0. Empty P, empty N, ε, unused symbols, duplicate words, and arbitrarily long finite word arrays are handled by the same criterion. A contradictory sample is INCOMPATIBLE; malformed input is INVALID_INPUT. Candidate-budget exhaustion, caught interruption, or caught resource exhaustion produce INCOMPLETE with null mathematical fields; an external hard termination cannot be promised a returned status. A witness-replay error is ERROR, not a data-incompatibility result.Identifiability, prior work, and evaluationAll-compatible uniqueness and optimal uniqueness are different. For Σ={a,b}, P={ε}, N={a}, both {a,b} and {a}|{b} are compatible, but only the latter has the optimal two blocks. More generally, a single universal factor over {a,b} and universal singleton factors over {a} and {b} have the same complete global language. Consequently even full membership behavior cannot recover which of those physical partitions generated it under the unconstrained model. If the assumed model is correct, an actual generator fits the observations, and exactly one partition is compatible, its partition is conditionally identified within the model; factor implementations and physical names remain undetermined. The RGS tie-break is deterministic, not a measure of confidence.The projection obstruction is closely related to prior compositional learning theory: Henry et al., A Detailed Account of Compositional Automata Learning through Alphabet Refinement, arXiv:2504.16624v3, §4.1, Proposition 5, and §6.1, Corollary 12, characterize incompatibility through a negative whose projections match positive observations on all local alphabets (paper).
