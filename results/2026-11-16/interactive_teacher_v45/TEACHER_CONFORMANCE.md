# Teacher conformance

`teacher_main.py` implements the fixed-partition decision procedure in Sections 5.1–5.3 of `C:\Users\Mahdi\Downloads\main.pdf`. The caller supplies already projected words; their negative lists must preserve the same global negative-word order. Positive projections determine the sufficient finite bound: one state for an empty positive sample, otherwise one plus the number of distinct prefixes, including the empty prefix. This bound is an experiment-specific choice, not a claim that the manuscript prescribes it.

For every size from one through that bound, the implementation enumerates every transition table on named states with initial state zero and every accepting subset. It tests all positive projections, constructs all negative rejection bits simultaneously, deduplicates rows, and stores a complete DFA witness per row. There is no symmetry breaking or projection-criterion shortcut. The original tables are cached by block, projected sample and bound, and published only after complete enumeration. Each global solve builds fresh tables, explicitly constructs the negative-disjunction relations, substitutes positive-forced zeros, constructs the responsibility graph, conditions non-tree edges, and performs upward and downward semijoins and compatible-row reconstruction on each resulting forest.

The caller's `tick` is invoked throughout enumeration and solving. Exceptions propagate, including deadline exceptions; an interrupted check is not a rejection and must be reported as incomplete by the caller. This does not claim that Python operations themselves are preemptible.

The enumeration is extremely expensive: a block of size s has sum over q=1..m of q^(s*q) * 2^q named DFA representations. Explicit negative tables can contain 2^k-1 rows each and cycle conditioning can require 2^t branches. The implementation is intended as a literal experimental teacher under a deadline, not as a practical optimized solver. It does not implement the manuscript's behavioral query or outer partition search; those are outside this interface.
