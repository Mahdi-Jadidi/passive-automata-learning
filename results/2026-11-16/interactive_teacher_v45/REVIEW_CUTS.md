# Review of generalized cuts and certificates

Reviewed `optimizer.py`, `verify.py`, `master.py`, and `spec.py`. No unsoundness was found in the cut argument or the acceptance of an optimum under the stated normalized sample semantics. This is a code review and bounded test evidence, not a formal verification.

- Rejection of a fixed negative is monotone under adding atoms: if a projection has no positive match, extending that projection cannot introduce one. The greedy scan extends each rejected candidate block only while it remains false. Once an atom cannot be added, subsequent extensions cannot make it addable, so the final region is maximal. Maximality is useful for strength but the consumer correctly needs only an explicit positive projection witness for each region.
- Every returned region contains its original block, so the learned cut eliminates the rejected partition. A compatible partition must contain a block rejecting the selected negative; that block cannot be contained in any witnessed false region. Thus every compatible partition survives every cut. The independent four-atom enumeration exercised 167 nonzero monotone Boolean functions, 758 generated cuts and 5,218 satisfying-partition soundness checks, as well as progress for every generated cut.
- Pair variables and their triple clauses encode equivalence relations. Minimum-index representative indicators and the fully equivalent threshold gates count blocks. Constants are tested by identity, avoiding confusion between Boolean constants and integer literals. `threshold(k+1)` expresses the strict improvement query, including the impossible threshold above the atom count.
- Cuts form a relaxation containing all compatible partitions; a feasible candidate of size k together with a refutation of the relaxation at k+1 therefore establishes global optimality. The search uses the full-alphabet block as its one-block lower bound; it is feasible after the direct contradictory-sample check. The mandatory groups are necessary: if deleting a symbol makes a negative indistinguishable from a positive, every block rejecting that negative contains that symbol. Therefore the forced symbols for each negative share a block in every compatible partition.
- The consumer independently validates the returned partition, normalized indices, proper region masks, projection witnesses, reconstructed CNF and DRUP additions. Ignoring proof deletion lines is sound: retaining additional clauses only strengthens the formula used for later RUP checks. The RUP checker is deliberately conservative for clauses with duplicate unassigned literals, which may reject some otherwise valid proofs; it does not establish an invalid proof. Empty proofs are accepted only when unit propagation itself refutes the initial CNF.

`cut_certificate_tests.py` constructs a nontrivial 14-line native Glucose DRUP certificate from a fixed sample and the master without calling MainTeacher; the independent consumer accepts it. Tests also reject altered regions, witnesses, negative indices, out-of-range witness indices, proofs, and unknown IDs, and exercise contradiction, empty alphabet, and zero-timeout handling. The four-atom finite enumeration and this fixture do not exhaust all samples or all possible proof encodings.
