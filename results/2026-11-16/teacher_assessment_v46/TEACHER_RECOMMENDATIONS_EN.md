# Teacher recommendations

The current evidence points to exhaustive local DFA enumeration as the dominant cost. Retain the existing teacher and its result semantics; no modification is applied by this assessment.

For immediate measurement, add external timing and counters around completed calls, record block size, derived bound, table size and interruption phase, and compare repeated identical calls. External memoization may reuse only fully completed results keyed by every semantic input, including projected labeled sample, block and bound; do not cache interrupted computations as decisions. Validate cached versus uncached outputs and retain reproducible cold and warm timings. Such instrumentation and memoization preserve semantics when correctly implemented, but add no claim of universal speedup.

For a future explicitly approved algorithm change, evaluate the proposed maximal rejection-row fast adapter only for the unrestricted-state feasibility call with the sufficient finite bounds, empty partial assignment β, and positive-OR negative obligations. The canonical local language of positive projections realizes the maximal rejection row, which dominates the other rows for that restricted decision. This is not a replacement for arbitrary partial assignments, local behavior queries, or the full manuscript teacher interface. Keep the exhaustive teacher as a reference and compare on small cases, including empty positive sets and epsilon. Independently check feasibility and optimum certificates against original words.

Other possible future changes, such as symmetry reduction, a SAT-based bounded teacher, altered table construction or partial-table pruning, change the internal algorithm and require separate future approval. Before adopting one, specify the exact preserved interface, prove equivalence, and benchmark against the reference with identical resource limits. The current request asks for recommendations only; none of these changes has been implemented.
