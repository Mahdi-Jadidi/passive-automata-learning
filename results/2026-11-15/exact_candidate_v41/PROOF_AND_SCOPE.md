# Exact residual-completion extension V41

This experimental revision adapts the V33 DP source, retaining its canonical witness reconstruction and frozen reference dependency. It is not a newly independent backend or a novelty claim. `candidate.solve` is the revised DP. `combined.solve` retains V33's certified singleton and forced-component routes, replacing its DP route with the revision. Both preserve explicit candidate-prefix budgets by invoking the historical reference for a non-None max_candidates, disclosed as a solving dependency for that mode. Unlimited DP uses reference validation/projection/witness helpers but not its partition generator. No SAT backend is called.

## Exact new reductions

Let D(S,U) be the polynomial counting partitions of remaining symbols S that reject uncovered negatives U, by block count. The original least-symbol anchored recurrence is retained, including unique block selection and full coefficients. If U is empty, every partition of S is allowed: coefficient k is the Stirling number of the second kind S(|S|,k). Thus an exponential anchored traversal at this node is replaced by an exact polynomial recurrence.

For witness reconstruction there can also be q already-open distinguished nonempty blocks. Let E(r,q,k) count assignments of r remaining distinct symbols into those q blocks and k new nonempty unordered blocks. E(0,q,0)=1, with other coefficients zero, and E(r,q,k)=(q+k)E(r-1,q,k)+E(r-1,q,k-1). Proof: remove the last symbol; either it belongs to one of q+k blocks already having a member, or it is the only member of one newly introduced block. The cases are disjoint, and each extension has a unique predecessor. With U empty, the `extend(j,available,U)` polynomial is E(|available|,q-j,k), since the remaining q-j open blocks already contain their fixed prefix members. This retains counts and canonical feasibility queries; no greedy approximation is introduced.

If U is nonempty and U is not contained in R(S), no completion exists: every possible future block B is a subset of S and monotonicity gives R(B) subset R(S). Returning zero coefficients is therefore sound. It removes no compatible partition and loses no optimal ties or canonical witnesses. Together these changes preserve the original recurrence's value at every state, hence C, k*, O and all prefix-feasibility decisions. Retained witnesses are still replayed against the original instance. Interruption returns INCOMPLETE, never partial exact counts.

The combined routes are exact only because each early route certifies the full family: compatible singletons imply every partition, and compatible forced components imply precisely all coarsenings of those components. Otherwise the full DP runs. These are deterministic exact certificates, not heuristic dispatch or probabilistic answers. Additional preprocessing can still cost time; there is no universal performance theorem. Uncovered-zero states avoid their previous subset traversal but extra infeasibility tests can add work elsewhere. State and witness complexity remain exponential in general.

## Validation and limitations

Revised DP and combined module each passed 2243 full-output comparisons against the frozen reference and insertion oracle, plus 536 budget and 27 invalid-input checks, using the V35 audit harness and local `audit_combined.py`. This is bounded testing, not independent source review or proof-assistant verification. Source still depends on exact frozen V28/V30/V33 files, whose digests the combined module checks. Dependency removal, production packaging, independent review and real-workload/memory evaluation remain open.

SAT lessons are preserved separately in `results/2026-11-15/sat_candidate_v40/REPORT_FA.md`: canonical logical encoding, blocking only y, projection tables over distinct IDs, incremental CDCL, and independent exhaustive count replay. SAT had no speed advantage on its measured completed cases, so it is not added as a compulsory step here. Hypergraph contributes the mixed symbol-exact/negative-at-least-one interpretation; the new code does not present that known interpretation as a novelty.
