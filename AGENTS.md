# Project research conventions

For new algorithm work, use `docs/ALGORITHM_NOTATION.md` as the shared notation
map to the user's latest manuscript. Current objective: given D=(S_plus,S_minus)
over declared Sigma, return one compatible alphabet partition P maximizing |P|,
with a checkable optimality certificate. There is no DFA state bound and no
requirement to learn local DFAs or count all compatible/optimal partitions.
Current research is exact; approximation/heuristic algorithms are a later phase.
Do not rewrite historical frozen files to change their notation or evidence.

Do not automatically create/fork/transfer/handoff chats or send their context
to another chat. Such actions require an explicit user request, regardless of
response count. Archiving/deleting chats requires separate authorization.
