# جست‌وجوی افراز با بازخورد شکست تصویری

این بسته برای یافتن یک افراز با بیشترین تعداد بلوک سازگار با نمونه، بدون کران حالت است. یادداشت [اثبات و مثال دستی](PROOF_FA.md) توضیح می‌دهد چرا برای تولید افراز بعدی، ادغام‌های بین بلوک‌های گواه شکست کافی‌اند. برای اجرای کد، پایتون ۳ و کتابخانهٔ استاندارد آن کافی است.

## اجرای مثال

فایل‌ها را کنار هم باز کنید و در همان پوشه اجرا کنید. در ویندوز می‌توانید به جای `python` از `py` استفاده کنید.

```text
python search.py example.json --output result.json
python verify.py example.json result.json
```

پاسخ مورد انتظار `OPTIMAL` با `blocks = [["a", "b"], ["c"]]` و `max_devices = 2` است. بررسی‌کننده `{"status": "VERIFIED"}` چاپ می‌کند. [خروجی ثبت‌شدهٔ مثال](example-result.json) شامل گواه کامل است.

## ورودی، خروجی و روش‌ها

- ورودی JSON سه فیلد `alphabet`، `positive` و `negative` دارد. الفبا فهرست مرتب نمادهای رشته‌ای یکتاست. هر رد فهرستی از نمادهاست و `[]` رد تهی است. ترتیب نمونه‌های مثبت و منفی و نمونه‌های تکراری برای ارجاع گواه حفظ می‌شوند.
- نتیجهٔ `OPTIMAL` افراز و گواه دارد. هر رکوردِ گواه، افراز آزموده‌شده، افراز گواه و شناسهٔ منفی و مثبت‌های شاهد را می‌دهد. شناسه‌ها از صفر شروع می‌شوند و ترتیب مثبت‌های شاهد با ترتیب بلوک‌های گواه یکی است. `INFEASIBLE` همراه با شاهد دو برچسب متضاد یا یک منفی روی الفبای تهی می‌آید. `INCOMPLETE` آمار اجرای جزئی دارد. گزینهٔ `--seconds` بودجهٔ زمانی اختیاری برای محاسبهٔ هر فرمان است.
- `--mode baseline` همهٔ ادغام‌های دوتایی را تولید می‌کند. `--mode first`، پیش‌فرض، بعد از نخستین ادغام موقتِ حافظ شکست می‌ایستد. `--mode maximal` تا وقتی چنین ادغامی ممکن است ادامه می‌دهد. هر سه روش آزمون تصویری یکسان دارند. ساخت سطح بعد پس از رد کامل سطح جاری انجام می‌شود.
- `--order gain` فقط ترتیب آزمون در یک سطح را تغییر می‌دهد. امتیاز فرزند شمار منفی‌هایی است که ادغام، تازه جدا می‌کند. هنگام وجود چند والد، بیشترین امتیاز نگه داشته می‌شود. تساوی با ترتیب بلوک‌ها بر اساس شناسهٔ نمادها شکسته می‌شود. پیش‌فرض `canonical` همین ترتیب را بدون محاسبهٔ امتیاز به کار می‌برد.
- بررسی‌کننده مستقیماً دادهٔ خام را می‌خواند. پس از آزمون سازگاری جواب، از ریشه سطوح ارزان‌تر را از روی رکوردها دوباره تولید می‌کند. هر گره در آن سطوح باید شاهد معتبر داشته باشد. رکوردهای شکست آزموده‌شده در سطح خودِ جواب هم بازپخش می‌شوند. بررسی‌کننده کد جست‌وجو را وارد نمی‌کند.

## بازتولید آزمایش

```text
python evaluate.py --seconds 0.5 --repeats 4 --output evidence-local.json
```

این فرمان ابتدا صحت را با پیمایش شمارشی مستقل روی نمونه‌های کوچک می‌سنجد و سپس زمان‌گیری ساختگی را انجام می‌دهد. [گزارش آزمایش](RESULTS_FA.md) و [ورودی‌ها و اندازه‌گیری‌های ثبت‌شده](evidence.json) همراه بسته‌اند.
