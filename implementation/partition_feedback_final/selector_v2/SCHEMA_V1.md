# Shared internal schema proposal — selector-v2/1 (issue #10)

Review requested from proof #3 and interface #5. This is a normalized selector format, not an external wire schema or operational certificate. Python producer implements schema.py, component_closure.py, evidence_store.py. All fields listed are required; unknown fields and versions rejected by intake. IDs are JSON integers, not booleans. Arrays have semantic order; object keys sorted in canonical JSON; compact separators, ensure_ascii=True, allow_nan=False, UTF-8 SHA-256 lowercase hex. Sample digest retains existing array encoding: ["sample-v2",alphabet,positive_encoded,negative_encoded]. Alphabet is declaration order, nonempty unique string symbols (empty alphabet raw-only extension, rejected in requests). Positive and negative IDs are separate positional IDs, including duplicates and epsilon.

## Record envelope

Every entry is {version,origin,sample_digest,kind,payload}, where version is selector-v2/1, origin RAW/SIMULATOR/EXTERNAL. RAW includes local mathematical facts and REQUEST control records. No origin label authenticates a source. Owner array length n maps each symbol to its minimum original block ID; canonical representative g has owner[g]=g and g<=a for each owner[a]=g. Every owner is complete over declared alphabet.

RAW kinds and payload fields:
- DELETE_EQUAL: {owner,fact:{negative,group,positive}}. Literal erasure of entire group (not occurrence, not relabeling) gives equality of original traces. Arbitrary snapshot is valid for equality only, not for mandatory union.
- COMPONENT_EPOCH: {epoch,owner,facts,edges,result_owner,state,cursor}. Zero-based contiguous epochs starting from singleton owner, each subsequent owner equals prior verified result_owner. facts are {negative,group,positive}, one per (negative,group). edges are {negative,a,positive_a,b,positive_b}; both witnesses must occur in same epoch facts, same negative, canonical groups, successful nonredundant union. Rebuild from prior verified components, union edges, compare result_owner and require all emitted groups for each negative joined. EXHAUSTED has cursor null; PARTIAL has [phase,index] with phase positive/conflict/negative and corresponding original index. EXHAUSTED is a producer assertion, not an independently proven completeness claim; edges are necessary regardless. PARTIAL or no-edge epoch terminates this closure stream; restart with a new ledger, no persistent resume. FIXPOINT is rule-class only, not global necessity. Outer closure result {state,owner,records} with state FIXPOINT/PARTIAL/LABEL_CONFLICT is producer metadata.
- LABEL_CONFLICT: {negative,positive}, exact full word equality; global structural infeasibility (including bounded feasibility). Terminates closure stream.
- STRUCTURAL_CHECK: {owner,compatible,separating_groups,failed_negative}. True: one canonical separating group for every original negative in order, failed_negative null. False: empty separating_groups, valid negative ID for which each block matches some positive. Empty alphabet raw-only extension: compatible iff no negatives.
- REQUEST: {version,scope,owner,request_id,attempt_id,negative_ids}. Scope fields {version,sample_digest,regime,family,capacity_digest}; regime UNRESTRICTED or BOUNDED; only ALL_PARTITIONS allowed; capacity_digest null for unrestricted and SHA-256 digest for bounded (actual policy/auth must be validated by interface owner). Request ID and attempt ID nonempty strings; negative_ids exact [0,...,q-1]. Unique attempt ID per ledger; repeated request ID must bind identical request excluding attempt_id. request_digest = hash of canonical request payload.

SIMULATOR/EXTERNAL kind OBSERVATION payload {request_digest,status,response_digest,receipt_digest,feedback}. Must reference registered request; at most one observation per attempt, retries require new attempt; unique nonnull receipt digest, no simulator receipts. response_digest and nonnull receipt_digest are references to artifacts, not authentication; conclusive external observation requires receipt digest. UNKNOWN may have null receipt. Status ACCEPT/PROJECTION_NO/BOUNDED_NO/UNKNOWN. No observation alone promotes operational ACCEPT or proves exact bounded NO. No observation modifies mandatory owner. Actual receipt, artifact/witness verification and binding to external bytes remain independent interface gate.
- PROJECTION_NO requires feedback {kind:"UNRESTRICTED_COMPLETE",failed_negative,tables}, tables sorted by canonical group, complete group coverage. Each {group,named_zeros:[{negative,positive}],anonymous_zeros:[negative IDs],free_groups:[[negative IDs],...]}. Full ordered negative ID coverage exactly once; each fixed zero literally matches a positive projection; free groups equal nonmatching projections, no split equivalent groups, no empty groups. Named witness for failed negative in every block. The table is unrestricted structural evidence even if the request regime is bounded. No assumption that a free group is compulsory rejection. 
- BOUNDED_NO only for bounded scope; feedback null or {kind:"BOUNDED_OPAQUE"|"CONDITIONED_OPAQUE",artifact_digest}. No interpretation as unrestricted table, no generalization. 
- ACCEPT and UNKNOWN feedback null in this proposal; ACCEPT DFA artifacts live in referenced response/receipt, require separate validation. UNKNOWN is pending, never a rejection.

EvidenceLedger.append(list_of_records) atomically stages the entire batch; valid entries stored as immutable canonical bytes, records property returns fresh decoded copies. Invalid batch quarantined with digest, reason, canonical bytes if serializable; no partial ledger state update. Replay serialized entries on new ledger to reproduce accepted raw owner. This is producer-side validation, NOT proof-agent independent replay. No durable storage, external transport, independent receipt auth, or incumbent API. Explicit full table checks are O(blocks * total trace length + table size), unsuitable for giant expanded tables; compact-reference protocol remains owner gate. No automatic merging or P3 search until independent review.
