# M3 proposal — CROSS_SUPPORT_LEX_V1

**Status:** for lead review. Structural P3 only, unrestricted ALL_PARTITIONS with B=0. M2 baseline is pinned at f8de4b6b14b3840d699d3c47ccc06a71eb5e04ae. This proposal concerns a future independently reviewed proof-rule extension.

## Necessary disjunction and coverage theorem

Let Σ be the complete ordered alphabet, S⁺ the ordered positives and S⁻ the ordered negatives. A region R(E,D) consists of the partitions P coarsening E and satisfying every original-ID disequality in D. Name each E-class by its minimum original symbol ID. For a set S of these representatives let U_E(S) be the union of the corresponding classes.

A witness is (i,j_s,j_t,S,T) with original trace positions i in S⁻ and j_s,j_t in S⁺, and nonempty, disjoint sets S,T of current representatives. Require exact ordered equality in both deletion checks:

- π_(Σ \ U_E(S))(y_i) = π_(Σ \ U_E(S))(x_(j_s))
- π_(Σ \ U_E(T))(y_i) = π_(Σ \ U_E(T))(x_(j_t))

Retain original tokens, repetitions, order and empty projections in both checks. Witness positives may coincide. Supports can come from sound raw deletion evidence lifted to whole E-classes, since enlarging the deleted set preserves equality on its complement. A smaller set requires its own valid check. No completeness assumption on witness discovery is needed. Equality in each chosen witness and completeness of the cross-pair family are required.

**Theorem.** For any P in R(E,D) compatible with S⁺ and S⁻, a block B separating y_i from *all* positives intersects both U_E(S) and U_E(T). Otherwise B lies in the complement of one deletion and projecting that witness equality again onto B gives a matching positive. Since P coarsens E, every E-class B intersects is contained in B. Thus some a in S and b in T lie in the same P-block. Let L be the lexicographically sorted family of (min(a,b),max(a,b)) for S × T. The children for the unique first true pair and the all-false residual are pairwise disjoint and their union is R(E,D). Every compatible P is in a child. The coverage identity follows by evaluating all pairs on P and taking the first true index, or the all-false case if none exists.

### Bounded witness discovery

For a first prototype, reuse raw deletion evidence whose two raw traces are available. For each candidate negative, lift each certified original-symbol deletion to the set of current E-class minima and deduplicate identical (negative ID, positive ID, support) triples. An optional deterministic probe tests supports of size one and two drawn from E-classes touched by the two words, using literal complement equality. Probe in original negative order, original positive order, then support size and lexicographic order, charging the whole probe and the disjointness scan to explicit budgets. The probe requires neither unused classes nor an exhaustive support lattice. It can find the root witness in the profiling report. A completed pair of disjoint witnesses can be used even if the probe stops early. Keep positive and negative IDs and original token sequences through lifting.
## Child construction, replay and interruption

1. Freeze both supports at the parent. A candidate witness record carries the three stable trace IDs and two ascending, strictly unique representative lists, with orientation canonicalized by lexicographic support tuple and the positive IDs swapped along with the supports. A discovery policy can choose the smallest product among the witnesses it finishes checking, with ties broken by numeric (i,j_s,j_t) then (S,T). Budgeted discovery with no completed witness falls back to ALL_PAIRS_LEX_V1. A global cap preserves unresolved work. Resume uses the committed witness and order.
2. Derive t = |S||T|. For sorted a in S∪T, row a contains ascending opposite-side b > a. Use row counts and cumulative offsets with sorted support arrays to locate pair_at(j) by binary search, using linear storage in |S|+|T|. Stream exactly prefix [0,cursor) in that order. Include pairs that D already forbids, with EMPTY closure if they are emitted. Descendant merges never reorder or shrink an ancestor family.
3. Child j is R(E ∨ {L[j]}, D ∪ L[:j]). Preserve every ancestor constraint. The residual is R(E, D ∪ L). It can contain strict coarsenings, but all of its members violate the necessary disjunction. It is eligible for CONFLICT_RESIDUAL bound to the independently replayed parent witness, including when also empty. EXACT_NO retains its singleton precondition. A nonempty suffix [cursor,t) represents exactly the ungenerated first-true children. A pause before atomic split admission leaves the parent OPEN. After admission, the residual and the suffix accompany the split, and a prefix advance commits the child, record and new suffix start together.
4. A verifier derives E0 from exact journal/2 replay and independently reconstructs parent E and D from original-ID paths. It checks canonical supports, class membership, disjointness, trace labels and positions, both deletion equalities, the complete family count and index mapping, each child edge, residual reference and suffix span. It accepts CONFLICT_RESIDUAL only on that split's all-false edge. An invalid witness, forged closure, malformed cursor, dropped suffix, orphan or false EXHAUSTED is INVALID. A valid unresolved frontier or verification cap is INCOMPLETE without an optimum result. Verify FEASIBLE_MIN, incumbent and optimum set independently using literal projections. Producer structures, hashes and discovery scores provide no proof authority.
5. The M2 max-lex threshold summarizes all-pairs prefixes only. For a mixed path, retain typed immutable ancestor prefixes and check them against current E. For a cross prefix [0,j), for each current class containing endpoints from both ancestor supports, its minimum internal cross pair is the normalized pair of the two side minima. An internal forbidden pair exists iff one of these minima pairs precedes L[j], or any such pair exists for a full prefix. Filtering by current class uses original endpoint IDs from the ancestor, even when those IDs are no longer representatives. An independent literal verifier can recompute this predicate without importing the producer representation. Use existing base cost n−|E| and its one/all cutoffs.

## Counterexamples

- **Support truncation and omitted alternatives.** S⁺={ab,c}, S⁻={ε}, identity E. Supports {a,b} and {c} have valid deletions. The only minimal choices are ac and bc. The compatible partition bc|a is lost both by truncating {a,b} to {a} and by retaining the valid witnesses but emitting only ac and closing the residual. Deleting a from ab leaves b, so independent witness replay rejects the truncation. Pair count must be two.
- **Overlapping supports.** S⁺={ab,bc}, S⁻={ε}. The deletion supports {a,b} and {b,c} are both valid. The block {b} hits both without joining any pair. Disjointness is essential to this distinct-class merge rule.
- **Mixing negatives.** S⁺={ε}, S⁻={a,b}. Deleting {a} witnesses the first negative and deleting {b} the second. The identity partition is compatible. The supports imply no merge between a and b.
- **Overlapping rank addition.** S⁺={aabc}, S⁻={abac,baac}. Each negative has singleton deletion witnesses {a} and {b} against the same positive. Their rank obligations each cost at least one from the identity, yet ab|c separates both at total cost one. Adding their ranks yields a false lower bound of two. Charging the ab merge again after E already contains it likewise overcounts. A future rank extension needs a bound on additional rank on current E and a proved rule for combining constraints, such as a checked packing. This proposal adds no rank bound.
- **Residual can be nonsingleton.** For the first example, ab|c also belongs to the all-false residual, along with a|b|c. Both are infeasible by the theorem. With S={1}, T={3} the selected pair (1,3) has an empty prefix. An M2-style global threshold at (1,3) would falsely forbid a later merge (0,2).
