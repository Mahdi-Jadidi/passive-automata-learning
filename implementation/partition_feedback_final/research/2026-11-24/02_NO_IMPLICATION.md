**Research assignment 02 | Alphabet partition selection | 24 November 2026**

## Executive summary

The external projection-failure response is substantially more informative than a binary NO. In the unrestricted model it describes exact local rejection possibilities, not the output labels of a globally consistent product. Existing code exploits same-negative zero-region containment, but discards identities that can be joined across regions and negative projection groups. The paper does not promise a positive witness ID for every zero column, nor tables on success, nor the same feedback after bounded-DFA failure.

This report introduces **Atom-Equivalence Feedback Closure (AEFC)**, a two-tier inference system:

1. **Named-witness closure.** Keep equivalence relations on trace IDs for each unary or binary restriction, generated by witnessed projection equalities. Intersect the classes on all atoms of a candidate block to reconstruct larger projection equalities, including equalities obtained through other negatives. A partition is forced incompatible if some negative has a matching positive class on every block. This is *complete for incompatibility entailment from fully named, unrestricted, opaque-ID histories* under the assumptions in Theorem 3. No enumeration of candidate corpora or partitions is needed for one target decision.
2. **Anonymous-witness closure.** A paper-style fixed zero without an ID is an existential disjunction over positives. Resolve it by explicit, exhaustive alternatives (or equivalent proof-producing Boolean reasoning). In every consistent alternative use the named closure. This is complete for arbitrary unrestricted paper-style table histories, including exact free-group constraints. A target can be universally incompatible even when its failing negative or positive witnesses depend on the alternative. Budgeted execution may prove less, never more.

The central new technical contribution is a **realizability theorem**: an arbitrary family of trace-ID equivalence relations on unary and binary alphabets is realizable by finite ordered words exactly when each binary relation refines its two unary relations. An explicit pair-gadget construction establishes the converse. Together with the least-equivalence-model theorem, it turns the previous report's bounded-corpus enumerator into a finite symbolic implication procedure, polynomial for the fully named case. The proof does not claim polynomial partition optimization or tractability of arbitrary anonymous histories.

For the actual input, all original words are known. Thus exact raw projection comparisons already determine unrestricted compatibility. Feedback cannot supply unknowable semantic information in that model; its value is reusable evidence, independent confirmation and avoiding repeated comparison work. The strongest history-only theorem is intentionally stated in a weaker opaque-ID information regime, to measure marginal feedback power. With literal traces available, independent verification must check those words. Final returned solutions still require the external ACCEPT and its witness output under the shared research contract.

## 1. Formal problem and scope

Let `Σ` be a finite declared alphabet of size `n`. Preserve symbol identity, occurrence order, repeated occurrences, original positive IDs `X={x_1,...,x_p}` and negative IDs `Y={y_1,...,y_q}`, including duplicate words with different IDs. Write `T=X ⊔ Y` for the `t=p+q` labeled trace IDs. An ID denotes one immutable ordered word. For a set of symbols `B`, `π_B(w)` erases symbols outside `B`. A partition `P` has nonempty pairwise-disjoint blocks whose union is exactly `Σ`. Use `P≼Q` for refinement (each block of P is contained in one block of Q). The objective is

```
maximize |P|, equivalently minimize c(P) = n - |P|.
```

For unrestricted complete local DFAs, define

```
E_B(u,v)  := π_B(u) = π_B(v)
D_B(u,v)  := not E_B(u,v)
Z_i(B)    := exists x in X: E_B(y_i,x)       # dead / positive match
S_i(B)    := forall x in X: D_B(y_i,x)       # separating / eligible
C(P)      := forall i exists B in P: S_i(B)
I(P)      := not C(P) = exists i forall B in P: Z_i(B).
```

`E_B` is an equivalence relation on all IDs, not on symbols. `Z_i` is downward closed and `S_i` upward closed. `I` is downward closed on the partition lattice and `C` upward closed. These are structural statements, not local DFA assignments. All positive projections must be accepted; the existence of a consistent product is exactly `C(P)` (main paper Lemma 1). Necessity follows from positivity; sufficiency follows because the finite set of positive projections on each block is a regular language. This establishes the mathematical semantics; the selector must not implement or replace the learner's DFA-building step.

**Scope distinction:** the main paper §2 assumes a nonempty alphabet, disjoint positive and negative *sets* of words, and optionally a supplied admissible partition family and fixed capacity function `m(B)≥1`. This assignment uses unrestricted local states, all complete partitions unless the coordinator supplies a restriction, and original ID lists. Duplicate words within a label are allowed in the engineering extension. Opposite-label equality establishes global unrestricted infeasibility, rather than an excuse to discard an ID. If `n=0`, there is one empty partition: compatible iff `q=0` (no block exists to reject a negative). If `n>0` and `p=0` or `q=0`, the singleton partition is structurally compatible. These edge cases are explicit extensions of the paper's domain; no assumption of unused-symbol equivalence in a bounded setting is made.

**Three distinct information regimes.**

- R (raw): fixed full literal words and declared alphabet. Compatibility and all exact unrestricted table relations are deterministic. Direct raw projection certificates settle any target, and a finite scan settles the whole lattice; this does not mean such a scan is cheap or that an inferred ACCEPT replaces the required external call.
- H (history): only IDs, alphabet, verified projection equalities/disequalities, table descriptions, and declared promises (e.g. cross-label disjointness). Words otherwise arbitrary. This is the regime of the new completeness results, useful even when raw facts have been only partly computed.
- B (bounded): fixed state-capacity policy. Projection evidence is still a necessary structural constraint. A bounded failure alone is a different fact, scoped to the exact partition and capacity configuration. No general bounded implication through refinement or coarsening is licensed.

For history H, let `Models(H)` be all ordered-word corpora realizing its licensed statements and its explicit domain promises. Define

```
ForcedNO(H) = { P : for every D' in Models(H), not C_D'(P) }.
```

Define a query `H ⊨ F` in the same way for any formula over the projection predicates. An empty model set is an inconsistent ledger, not a permission to exclude everything. For a fixed actual corpus `D`, `ForcedNO(H)` is contained in `I_D` whenever `D` realizes H. `UNKNOWN` means not proved; neither inferred compatible nor inferred incompatible.

## 2. Exact black-box interface reconstructed from the main paper

Source: supplied *Passive Compositional Automata Learning from Global Logs*, pp. 3–4 (§2), pp. 12–14 (§5.1, Fig. 2, Eq. 23), pp. 23–24 (Appendix B.1), pp. 28–31 (B.5–B.6). ### 2.1 Complete projection NO

For a submitted complete `P`, §5.1 returns:

- P and the ordered global negative indices;
- one failing negative `i*`;
- one positive witness `x_B` per B in P for that negative;
- one complete unrestricted table `R_B^∞` per B (possibly passed by reference).

Let `U_B = {π_B(x): x∈X}` and `v_Bi=π_B(y_i)`. A row `r∈{0,1}^q` is allowed exactly when

```
v_Bi ∈ U_B  => r_i = 0
v_Bi = v_Bj => r_i = r_j.
```

Bits: 0 local acceptance; 1 local rejection. All local DFAs considered by this table accept the positive projections; no global cover constraint or capacity bound is part of this relation. Every satisfying row is realizable by one unrestricted complete DFA (paper §5.1). Consequently each distinct negative projection outside `U_B` contributes one independent free bit. All other columns are fixed zero. With `f` distinct free groups there are `2^f` rows, including the all-zero row and the unique maximal rejection bit vector. **No individual column is fixed one in a complete base table**, since the universal language is always admissible. A 1 in even one sound base row proves separation; it does not prove mandatory rejection. Example 10: on `{a}` the rows `(0,0,0)` and `(0,1,1)` correspond to negative IDs ba, baa, aba for positive ab. The first is fixed zero, the second and third are free and share a projection. On `{b}` the table is all zero.

The paper guarantees named positive witnesses for `i*`, not one positive ID for every other fixed zero. A fixed-zero column still proves `Z_i(B)`. The compact mathematical representation is fixed zeros and groups of IDs with equal projections. If an explicit group relation is guaranteed to be the exact partition by projection (including zero groups), then its groups and their distinctions license `E` and `D` for all those columns. If only the row relation, or fixed zeros plus free groups, is available, the equality partition among fixed zeros is *not* identifiable. This report supports both cases; the adapter must negotiate which is delivered, not invent zero-group distinctions from constant columns.

### 2.2 ACCEPT and bounded failure

Unrestricted success returns the partition and complete local DFA witnesses (the paper's prefix-tree construction). No unrestricted table payload on success is guaranteed. Bounded success returns witnesses and, within `CheckPartition`, a joint rejection row; this is not a full base table nor a universally forced row. A witnessed local rejection proves structural separation; an accepting bit from one witness proves neither a projection equality nor fixed-zero status. Any universal acceptance/rejection statement about *globally consistent tuples* requires a nonempty feasible class and is scoped to that partition and capacities. No such marginal statement is inferred from an empty join.

A proposal failing the structural test returns `R_B^∞` even in a run with state bounds. A proposal passing that test but failing `CheckPartition` yields a conclusive bounded FAIL for that partition under m (§5.1, §5.2, §7). The paper explicitly leaves a richer failure interface open. Appendix B describes internal unfiltered bounded tables `R_B`, reduced working relations, conditioning and global joins. They are not guaranteed external feedback. The selector neither inspects them nor reconstructs missing fields from them. If a future interface supplies verified full unfiltered bounded tables keyed by `(D,B,m(B))`, they can be reused for identical blocks under the same bound; that optional extension is outside AEFC's completeness claims. A reduced relation is partition/branch-specific; it cannot be reused as a base table.

**Fixed-zero caveat:** a complete *bounded* base table can be all zero on a column without a matching positive. E.g. bound 1, positive a, negative aa, block `{a}`: any positive-consistent one-state complete DFA accepts everything. Likewise equality of two nonconstant columns in a bounded table need not identify word equality; state limits can correlate distinct projections. Hence no unrestricted equivalence extraction from a bounded table unless an independently justified raw projection fact is supplied.

### 2.3 Normalized status contract

| Observed event | Record as proven | Do not infer |
|---|---|---|
| Complete projection NO with licensed tables | I(P), named failure equalities, all licensed table facts | Any particular coarsening fails; globally forced local labels |
| Complete unrestricted ACCEPT with valid output | C(P), optional structural separations from verified rejecting witnesses | A table that was never delivered; acceptance of refinements |
| Complete bounded FAIL | Exact scoped `BoundedNo(P,m,D)`; separately supplied projection facts only | I(P), refinement/coarsening failure, zero regions from capacity zeros |
| Complete bounded ACCEPT | Scoped feasible incumbent, and structural C(P) | Bounded feasibility of coarsenings |
| Incomplete / timeout / interrupted transfer | Operational observation; optionally independently verified raw facts in separate transaction | NO, absent columns as zeros, complete table fixedness |
| Malformed / mismatched response | Quarantine, no new proof facts | Any logical conclusion from the malformed portion |

A complete verdict with genuinely missing optional tables is different from a timeout: a trusted conclusive verdict may be logged for that exact P, but without a structural-failure certificate do not generalize it. A bare explicitly certified unrestricted incompatibility does imply refinements by monotonicity, even without named IDs; it is not the complete §5.1 payload and is handled as an optional weaker fact. An untyped `NO` must be resolved by the interface version/regime, not assumed structural. No RPC schema or live instance is provided here; the adapter contract remains to be confirmed with the black-box owner.

## 4. Inference language and rule catalog

Use immutable statements with a sample fingerprint, scope, source response ID, payload location and provenance. Let A(B) consist of the singleton and unordered two-symbol subsets of B; call these *projection atoms* (not mandatory symbol-contraction components).

The notation `Fact ⊢ conclusion` means the conclusion has a proof DAG whose leaves are verified observations. Every conclusion below is universally valid for the stated premises. This catalog distinguishes complete unrestricted base tables, partial sound rows, raw facts, and bounded facts.

| Rule | Exact premises / licensing observation | Conclusion | Scope and proof |
|---|---|---|---|
| F01 named zero | Returned positive witness x for y_i on B, or raw equality | E_B(y_i,x), Z_i(B) | Positivity; valid structurally under any bound |
| F02 anonymous zero | Exact unrestricted base column identically 0; or explicit certified positive-match marker | `∨_x E_B(y_i,x)` | Eq. 23 + realizability; NOT a particular x |
| F03 eligible | A 1 in a sound positive-consistent local row; complete free group; or raw all-positive mismatch | S_i(B), equivalently `∧_x D_B(y_i,x)` | Positive projections cannot be rejected; true even if the row is bounded |
| F04 equal group | Explicit verified equal-projection group; OR two free columns always equal in complete unrestricted base rows | E_B(y_i,y_j) | Independent free labels otherwise allow unequal bits |

| P02 separation inherit | S_i(B), B⊆U | S_i(U) | Extend all differences |

E04 is established in prior report and paper for literal comparisons. The new contribution is its systematic completion with equivalence closure, realizability, and case splitting. E05/E06 are useful incremental clause propagation, not needed for named forced-NO completeness (but useful for deriving separations or pruning anonymous branches). P08/P09/P10 export evidence to the exact-search/lower-bound module; do not restrict actual merge generation here. E10 is not the claim that disjoint ID domains alone contradict an equality; two different positive IDs can project identically. When equality transports a zero from one negative to another, the *conclusion* is indexed by the target negative and its proof proves the bridge. That is the only permitted sort of cross-negative transfer here.

**Provenance rules for incomplete rows.** A zero in one sound row is not F02. A 1 in any genuine positive-consistent row licenses F03 even if not all rows supplied; if the response is incomplete, policy defaults to no ingestion unless the individual row/fact is authenticated and independently checked. A missing column is UNKNOWN, not zero. A fixed one in a conditioned table may express a responsibility of that particular solver branch; do not interpret it as a projection relation or reusable mandatory local label. A complete explicit table of size `R×q` must have nonempty row set, all-zero row, equal free-column signatures grouped, and exactly `2^f` distinct free-bit combinations to claim the unrestricted normal form; an asserted complete compact representation can be checked without enumerating rows. Exactness relative to the actual sample is independently verified by projections when needed.

## 5. Mathematical foundations and strongest history-only closure

### Lemma 1 — atomic characterization (established)

For any two ordered words u,v, any B,

```
E_B(u,v) iff ∧_(A ∈ A(B)) E_A(u,v).
```

Proof: left-to-right follows by erasure. For right-to-left, singleton projections determine counts of every symbol. Label each occurrence by its symbol and rank among occurrences of that symbol. In each word the same occurrence labels exist; same-symbol relative order is determined by rank, and different-symbol relative order is determined by the binary projection. All pairs of labeled occurrences have the same relative order. Thus the entire projected word is identical. The empty projection agrees trivially. QED. This is equivalent to main paper Lemma 2 and the alphabet-partition report's discrepancy lemma. It is about ordered words, not multisets.

### Theorem 1 — exact realizability of atom equivalence systems (new candidate result)

Let n,t be finite and `R_A` an equivalence relation on t labeled trace IDs for each unary or binary A. Such a family is realized by finite words over Σ, with `u R_A v iff E_A(u,v)`, **if and only if** for every pair `{a,b}`,

```
R_{ab} ⊆ R_a ∩ R_b.
```

There are no further consistency conditions among the binary relations in the unrestricted arbitrary-word regime. A realizing word for each ID has length at most

```
2 * ceil(log2(max(2,t))) * binom(n,2) + n*(t-1)  (t≥1).
```

Proof (necessity): erasure from `{a,b}` to a and b yields the inclusion.

Proof (sufficiency): fix one common ordering of all unordered symbol pairs and of all symbols. For each A=`{a,b}`, assign each `R_A` class a unique binary code of length `h=ceil(log2(max(2,t)))`. For ID u, in the segment for A encode each bit by `ab` for 0 and `ba` for 1. Concatenate all pair segments in the common pair order. Every pair segment uses exactly h copies of each endpoint, independent of its class. Next, for each symbol a append a run of a whose length is the integer class index of u under `R_a` (distinct indices 0,...,t_a-1, all below t), using the common symbol order.

A singleton a sees h copies from every incident pair segment plus its unary-class run, so equality is exactly R_a. For restriction `{a,b}`, every pair segment other than its own projects to the same fixed unary string or empty string for all IDs. The own segment occupies a common, fixed-position interval of length 2h and encodes its class uniquely. The final unary suffix is `a^{c_a} b^{c_b}` or the reverse order, independent of u except for its counts. Equality of the two projected words therefore holds exactly when the pair codes and both unary counts agree. By the refinement hypothesis, equal pair class already guarantees both equal unary counts. Thus the binary equality relation is precisely R_ab. The bound follows by counting segments and maximum suffix length. By Lemma 1, all larger projections are now determined. For n=1 there are only unary runs; for n=0 every word is empty, and the full-alphabet equivalence is universal. For t=0 the assertion is vacuous. QED.

**Why this matters:** the previous alphabet-partition report gives a finite word-length bound based on marks pooled over trace pairs. Even with that bound, brute corpus enumeration is enormous. Theorem 1 supplies an exact finite *structural* model instead, with simple local refinement constraints and a constructive countermodel. It does not require planted words, hidden automaton states, or access to internal learner variables. These artificial words are mathematical countermodels only; never feed them into the external learner or replace the actual sample.

### Theorem 2 — least equality model for named evidence (new algorithmic result)

Suppose H consists of named projection equalities, projection disequalities, and other **difference-monotone** constraints (a formula that remains true when more projection pairs become unequal), all scoped to one unrestricted corpus. In particular, complete free-group relations, separating facts, cross-label word disjointness, and conclusive unrestricted ACCEPT predicates are of this form once named equalities are extracted. All fixed-zero facts must have a licensed positive ID, or an already-proved named witness. No other existential equality or fixed-literal/count constraints are implicit.

For each A define `L_A` as the equivalence closure of edges `(u,v)` from every witnessed equality E_U(u,v) with `A⊆U`. Then:

1. Every realizing corpus's atom equivalence relation contains L_A.
2. Each L_ab refines L_a and L_b.
3. If the ledger is realizable, the family L itself satisfies all H and has an ordered-word realization.
4. Conversely, if any difference-monotone constraint is false in L, H is inconsistent.

Proof: 1 is E01 and equivalence closure. For 2, every edge used for L_ab also appears in L_a and L_b; any chain therefore survives in both. For 3, apply Theorem 1 to L. The resulting words satisfy all named equalities by Lemma 1. Let D* be any realizing corpus. L_A⊆R_A(D*) for every A implies that every projection disequality true in D* is true in L, since equality on B is the intersection of all atomic relations. Therefore every difference-monotone premise true in D* is true in L. This proves 3, and the contrapositive proves 4. QED.

**Equivalence-signature query.** For block B, let `sig_B(u)` be the tuple of class representatives `find_A(u)` over A(B) in deterministic order. Then E_B(u,v) holds in L iff `sig_B(u)=sig_B(v)`. Each equality is proved by paths of named edges at each atom; distinctness of these signatures is only absence of a forced equality in the least model, not a proof of actual difference.

### Theorem 3 — complete forced-NO decision for fully named histories

Under Theorem 2 and consistent H, a complete candidate P is in `ForcedNO(H)` exactly when

```
exists y_i: for every B in P,
    sig_B(y_i) belongs to {sig_B(x): x∈X}.
```

Equivalently, I(P) holds in the least equality model L. If so, a certificate consists of the same negative ID, one positive ID per block, and atomic equality-chain proofs for each block/positive pair. If the test fails, a finite compatible corpus consistent with H exists (construct it by Theorem 1), so no stronger sound history-only incompatibility rule can exclude that P.

Proof: if the test holds, every named equality in each signature match is forced in every model by Theorem 2(1) and Lemma 1. The failing negative matches on every block, so every model is incompatible. If the test fails, every negative has some block whose signature is absent among positives; thus C(P) is true in L. Theorem 2(3) realizes L with a corpus satisfying H and C(P). QED.

This is complete for *all forced-incompatibility conclusions* in the named history regime, not just closure of individual region predicates. It also characterizes all forced named projection equalities: exactly the atomic intersections of L. It is **not** complete for actual acceptance or arbitrary forced disequality conclusions using signatures alone. A distinct signature can be made equal in a different model. To prove a disequality, test H plus the negating named equality for inconsistency (Theorem 2 or Theorem 4). If H contains fixed literal words, exact numerical counts, exact lengths, or an arbitrary restriction on allowed corpora, Theorem 1 may not preserve those promises. For partial raw equality/disequality observations the theorem remains exact; for stronger literal constraints it is a sound relaxation only.

**Special cases:** one positive, one negative and all-zero NO histories gives the prior clique characterization: a candidate block must have all singleton/pair restrictions co-tested with a named equality. The previous single-NO sharpness follows also: when a target block crosses a query boundary, that pair has no named equality edge, so in the least model all IDs are separate there unless additional side facts constrain it. Complete rows and witnesses at the queried blocks remain valid. All fixed-zero witnesses named in the local adapter satisfy this theorem's input conditions. Even if only the reported failing negative is named, anonymous columns remain outside Theorem 3 until resolved.

### Theorem 4 — complete anonymous-history inference by witness alternatives

Consider exact unrestricted history H with named and anonymous zeros, known projection group equalities and disequalities, exact base table semantics and optionally difference-monotone constraints. Every anonymous zero `z=(i,U)` means `∨_(x∈X) E_U(y_i,x)`. If several zeros have an explicitly certified equal projection on U, one representative may be used with a proof of transport. For each zero choose one positive ID from its full or soundly reduced domain W_z. A choice vector θ generates H_θ by replacing each disjunction with the selected named equality; keep all other constraints. Compute L^θ as in Theorem 2 and discard inconsistent choices by checking the difference constraints. Then, assuming at least one consistent θ exists,

```
P ∈ ForcedNO(H) iff every surviving θ satisfies I_{L^θ}(P).
```

Proof: every corpus realizing H chooses at least one matching positive for each anonymous zero, hence belongs to the model class of some H_θ. Conversely every model of any H_θ satisfies H. Thus `Models(H)=⋃_θ Models(H_θ)`. Theorem 3 characterizes forced incompatibility in each nonempty component. Universal quantification over the union gives the assertion. A single surviving L^θ with C(P) yields an actual finite countermodel via Theorem 1. QED.

This is exact even when different branches exhibit different failing negatives. Requiring one globally forced failing ID would be an unnecessary restriction. A branch is inconsistent only if a licensed difference/constraint is violated by its least model (or a checked domain becomes empty); do not discard a choice on the basis of predicted likelihood. An anonymous zero can be omitted for a **relaxation** to get a sound but weaker NO proof; all alternatives of every included zero must still be covered. A budget cut yields UNKNOWN unless a complete proof was already obtained. The worst-case number of branches is `∏_z |W_z|`. For an exact complete anonymous closure there is no claim that this product is polynomial.

### 5.1 Complete finite logic for arbitrary feedback implications

For broader H with Boolean combinations (e.g. a bare structural NO without witnesses), introduce Boolean `e[A,u,v]` for unordered trace pairs, reflexive equality constant true. Add equivalence transitivity clauses for each atom (symmetry by indexing) and refinement `e[ab,u,v]→e[a,u,v]` and similarly for b. For every named region predicate needed, introduce or expand

```
E_B(u,v) ↔ ∧_(A⊆B, 1≤|A|≤2) e[A,u,v]
Z_i(B)   ↔ ∨_(x∈X) E_B(y_i,x)
S_i(B)   ↔ ¬Z_i(B)
C(P)     ↔ ∧_i ∨_(B∈P) S_i(B).
```

Encode the actual observed equalities, inequalities, group data, anonymous zeros and conclusive verdicts with these definitions. If the paper's disjointness is a promised input condition, add `¬E_Σ(x,y)` for each opposite-label pair. If same-label distinctness is promised, add the corresponding clauses too; do not enforce it on list inputs with duplicate IDs. Tseitin definitions prevent syntactic explosion of nested formulas. If H is satisfiable, `H ⊨ F` iff the finite formula `Axioms ∧ H ∧ ¬F` is UNSAT. Soundness: every word corpus maps to a satisfying assignment. Completeness: every assignment's atomic equivalence relations satisfy Theorem 1, which constructs a corpus realizing the assignment's region predicates. Hence the formula is exact for arbitrary Boolean properties of projection predicates on the fixed ID set. SAT is an optional **selector-side logical proof mechanism**, not a bounded-DFA learner or additional external oracle. A custom branch checker suffices for the main NO interface.

Full closure of *all* candidate verdicts may still need Bell(n) outputs; represent it as predicates or proof-producing queries rather than listing partitions. The finite formula is compact relative to corpus enumeration, not necessarily small in n or t. For arbitrary literal/count facts outside this logic, the raw corpus must be retained or a stronger exact theory used; a relaxed UNSAT proof remains sound but SAT is not a countermodel respecting those extra facts.

### 5.2 Why the anonymous extension can be hard

A hardness result for the **generalized partial-evidence consistency problem** (not a claim about histories promised realizable by the paper's protocol): reduce graph 3-colorability. Use three positive IDs and one negative ID per vertex, alphabet `{a,b}`. Give every vertex a zero on `{a}` (must match one of three positives), and for each edge give the licensed-type partial raw disequality `D_{a}(y_u,y_v)`. A realizing assignment induces a proper coloring by positive witness index; adjacent vertices cannot match the same positive. Conversely, assign the counts of a to the three colors, and add distinguishing b-runs so full opposite-label words are distinct (and all same-label words can be distinct if needed). This realizes the constraints iff graph is 3-colorable. Theorem 1 gives polynomial-size certificates of model existence for this projection-predicate language; checking them is polynomial. Thus consistency of general anonymous-zero plus raw-disequality ledgers is NP-complete. Named-only consistency does not suffer this reduction, because color choices would already be fixed. This does **not** prove coNP-hardness of forced NO for consistent actual feedback histories, nor imply that all useful closures are hard. The paper independently proves NP-completeness of maximum block-count optimization (Theorem 1 there), even for length-two traces. Our polynomial named *target* inference does not solve that optimization in polynomial time.

## 6. Worked examples and adversarial counterexamples

### 6.1 Genuine additional closure beyond zero regions: named stitching

`Σ=abcd`, `X={x=abcd}`, `Y={y=abdc}`. Query complete partitions `ab|c|d`, `ac|b|d`, `bc|a|d`. All are projection NO, and each block's witness is x. Candidate `abc|d` was never queried. No known region contains abc. Atomic evidence for the same x,y on `{a,b}`, `{a,c}`, `{b,c}` and all singletons proves E_abc(x,y). E_d(x,y) is direct. Thus candidate is NO. Words are disjoint as required by the main paper; `{c,d}` is an order discrepancy that can separate. This is a nondegenerate extension of the prior clique example (which used full equality); the underlying named stitch itself was known.

For cross-ID stitching, let `E_ab(y_1,y_2)`, `E_ab(y_2,x)`, `E_ac(y_1,x)` and `E_bc(y_1,x)` be licensed. E03 first yields E_ab(y_1,x); E04 yields E_abc(y_1,x). The equality paths can use different intermediate traces for different atoms. No common path on abc is necessary. If a required group equality is unknown, it cannot be supplied by the fact that two columns happen to be zero together.

### 6.2 Strictly stronger anonymous case-splitting inference (new concrete example)

Use declared alphabet `abcde`, two positives `x1=abcd`, `x2=bace`, two negatives `y=abcde`, `z=abced`. All four words are distinct. The paper permits returning any one failing negative and its witnesses. The following five complete queries all return projection NO. Assume other fixed-zero columns are described without positive IDs and that only free groups/row relations, not exact zero-group distinctions, are supplied.

| Query | Named failing negative | Named positive witnesses, in displayed block order |
|---|---|---|
| `acd|b|e` | y | x1, x1, x2 |
| `bcd|a|e` | y | x1, x1, x2 |
| `ace|b|d` | y | x2, x1, x1 |
| `bce|a|d` | y | x2, x1, x1 |
| `ab|c|d|e` | z | x1, x1, x1, x2 |

All base columns in these queries are fixed zero for both negatives, because the local projections of y and z coincide on those queried blocks (no block contains both d and e). The row relation alone does not disclose that coincidence between y and z. In particular the last query tells us `Z_y(ab)` without naming its witness. The first four queries establish that **both** x1 and x2 agree with y on ac and bc, and hence on their singleton atoms. For candidate `abc|d|e`:

- If x1 witnesses the anonymous Z_y(ab), atomic stitch gives E_abc(y,x1).
- If x2 witnesses it, atomic stitch gives E_abc(y,x2).
- On d and e, y has named witnesses x1 and x2 respectively.

Therefore candidate is incompatible in both alternatives. Neither containment (no abc region) nor named equality closure alone (no named equality for y on ab) proves this. In the least named model both y and z may be separated on abc. The supplemental validation script checks the strict gap, both consistent witness branches, and target failure. The proof only needs one anonymous zero; other anonymous facts can be dropped from the exact-history premise as a sound relaxation.

**Interface sensitivity:** if the external response includes explicit equal-projection groups among all fixed zeros, the z–y equality on ab plus z's named witness may already prove the target by named stitching. If all zero witnesses are supplied as in the local adapter, the extra branch is unnecessary. The example demonstrates strict added strength for the legitimate weaker row-only representation; it does not assert the actual service omits exact zero groups. Likewise the paper permits the displayed sequence of failing IDs, whereas the local adapter always picks the first failing ID.

## 7. Compact representation, closure, and redundant evidence

### 7.1 Keep two logically different indexes

A single maximal-region antichain is not enough for full feedback inference.

1. **Verdict index:** per negative i, store inclusion-maximal dead regions `Zmax[i]` and inclusion-minimal known separating regions `Smin[i]`. A zero region U is redundant in this index if U⊆V for another region V of the same negative. A separating region V is redundant if U⊆V for another separating U of the same negative. These are sound subsumptions of monotone predicates. An anonymous zero can populate Zmax without choosing a positive ID. A table-derived free column populates Smin.
2. **Identity index:** named equality records `(u,v,U)` over original IDs. For the *same unordered trace pair*, a larger equality region dominates a contained smaller one. This is not true for different positive IDs. For example, let y=abc, x1=abc, x2=ac. E_a(y,x1) is contained as a region in E_ac(y,x2), but deleting the first equality could remove a necessary named chain involving x1. Keep identity-specific regions even if their anonymous zero effect is redundant. For disequalities the inclusion direction reverses. Store free-group equality as representative/member stars rather than a clique of all ID pairs; represent distinct free groups as a typed group-disequality constraint rather than expanding all pairs up front.
3. **Proof/provenance store:** immutable raw records and derived proof DAG nodes; indexes are disposable accelerators. Logical redundancy never erases the original response referenced by a proof. Store only a durable reference to external payload bytes if the reference is guaranteed retrievable for independent replay. Otherwise archive normalized observations and their authenticity material. Hashes are integrity checks, not mathematical proof of semantic truth.
4. **Anonymous obligations:** `(negative_id, region_id, allowed_positive_domain, proof_ids)`. Default domain is all positive IDs; represent as a universal set minus proved exclusions. Merge identical obligations with multiple proven sources. For the same i, Z_i(U) with larger U implies Z_i(B) for contained B, so the smaller anonymous zero can be omitted from *logical* constraints if it has no additional witness/group information. Keep it in the provenance store. A named zero can discharge an anonymous obligation by containment or equality proof. Do not merge two domains solely because their regions overlap.

### 7.2 Incompatible families and subsumption

The cheap exclusion predicate already implemented is

```
I_reg(P) = ∨_i ∧_(B∈P) [∃ U∈Zmax[i]: B⊆U].
```

It compactly represents a union of downward-closed partition families without listing their members. The exact named history predicate replaces the bracket by `∃x: sig_B(y_i)=sig_B(x)` (Theorem 3); the exact anonymous history predicate is the intersection of the exact named predicates across all consistent alternatives (Theorem 4). Each is downward closed, so a proved structural NO also represents its complete refinement cone. The direct cone of Q has `∏_(U∈Q) Bell(|U|)` partitions, including Q; this count does not equal the number of avoided paid queries. Anonymous branch intersection is not a union of exclusions; the target must fail in **every** possible corpus branch. A union would be unsound.

Some additional safe compressions:

- An explicit stored NO partition Q is redundant as an exact/cone record if Q refines another proven structural NO P. Do not delete its table evidence. For bounded NO exact-key deduplication only.
- If every dead region of i lies within some known dead region of j, all partitions covered by i's current region predicate are also covered by j's. This is subsumption of the *exclusion family*, not equality of the negative traces. Do not discard the original evidence or drop negative i from the overall compatibility model. Recompute subsumption after updates; j need not dominate i's future evidence.
- Equivalence classes can be represented by union-find plus a proof forest. At each atom, a newly inserted edge within an existing component needs no new union; keep its source as an alternative shorter proof if worthwhile. A star of k IDs requires k−1 edges, not k(k−1)/2. An equality is redundant if all its contained atoms already prove it (budget permitting). This may save storage but checking it can cost more than storing the original compressed region.
- Derived region unions are permitted only if the same positive equality is proved on all atoms of the union, or a complete witness case split proves Z_i of the union. Never use the mere union of regions as evidence.
- For complete inference with named evidence, no enumeration of maximal dead regions, maximal cliques or minimal separating sets is required. Query signatures on candidate blocks. Such enumerations can be exponential even when the atom representation is small. Example: positive single-symbol words for each symbol and negative ε; a separating set needs all symbols. For exponentially many minimal separators, use positives `a_i b_i` on disjoint pairs with negative ε (paper Example 12). Do not eagerly generate these sets.

### 7.3 Cross-block constraints for other modules

From an explicit structural NO Q, export a symbolic constraint `∨_{a,b from different Q-blocks} Same_P(a,b)`. It is necessary for every feasible P; represent by Q itself rather than constructing the dense disjunction. From Zmax export complement support sets (P08) and optionally already-proved mandatory pairs (P09). For a stronger anonymous case-split result, export its proved incompatible P and corresponding cone, or a certified derived zero when the same block is dead in every branch. Do not claim one particular witness or failing negative is invariant across branches.

An exact coarsening-branch or incumbent cutoff is the responsibility of the exact search module; this module supplies structural I(P), regions, or necessary constraints. It does not assert that a merge path below an incompatible node is useless. It also does not rank queries. Any mandatory co-membership must be justified in the original alphabet, then transported into current DSU atoms of symbols. The trace-ID DSU used for AEFC and the symbol DSU used for mandatory merges are distinct structures and must never share equivalence state.

### 8.3 Parse and ingest

```text
parse_feedback(response, request, registry, schema):
    verify request fingerprint, unique query ID, response type, regime
    verify exact submitted partition over declared alphabet, including unused symbols
    verify response binding, trace-ID mapping, table keys and references
    if timeout or partial transfer: return INCOMPLETE (no whole-table facts)
    if exact scoped bounded FAIL:
        return BOUNDED_NO with separately licensed structural facts, if any
    if ACCEPT:
        validate required witness payload under negotiated external schema
        # do not fabricate absent tables; local mock profile permits different fields
        return scoped ACCEPT
    require complete projection failure in this profile
    require exactly one table per submitted block
    require each complete base table covers every original negative ID exactly once
    require disjoint nonempty free groups; validate zero witnesses and ID ranges
    if explicit full groups: require exact group schema and status consistency
    if row list: check complete normal form (§4), not just all-zero flags
    require named failing negative belongs to original Y
    require its witness on every block and its zero in every complete base table
    require at least one such failed column, no conflict with verdict
    return PROJECTION_NO

extract_proven_facts(parsed):
    if INVALID or INCOMPLETE: return empty batch with operational log
    add scoped conclusive verdict leaf
    for each supplied licensed failure witness: emit EQ and ZERO (F01)
    for each complete unrestricted base table:
        emit ZERO for every fixed-zero column (F02)
        emit EQ for every actually named zero witness (F01)
        for each free group G:
            emit SEP for all members (F03), representative equality star (F04)
        emit symbolic distinct-free-group and zero-vs-free constraints (F05)
        if exact projection groups explicitly supplied:
            emit their equality stars and distinct-group constraints
    for individually licensed, positive-consistent, verified sound rows:
        emit SEP from ones and NEQ from unequal bits only
    return fact batch with proof leaves and source coordinates

update_evidence_ledger(ledger, batch):
    validate entire batch and same sample/regime scope; normalize structural facts
    detect conflicts with existing actual raw facts and conclusive verdicts
    stage all index changes transactionally
    insert proof leaves and provenance; deduplicate region handles
    update Zmax/Smin and identity-specific EQ/NEQ indexes separately
    register unresolved anonymous obligations (not one guessed witness)
    update or invalidate cached affected atom equivalences
    enqueue newly provable zero/sep/domain/transport facts for lazy closure
    detect contradictions; if detected, quarantine batch and stop certified search
    commit version atomically; return update statistics
```

A schema-only check cannot establish truth of an external observation. The response is an observed premise only if authenticity and exact semantics are part of the interface trust model. In this project, raw words are known, so at minimum independently verify every proof leaf that is used in a prune: named equality by direct projection, anonymous zero by a positive lookup, free SEP by comparing all positive projections, and group equality/disequality by the two named projections. Optional intake validation of all tables is stronger but may cost substantial raw work; report separately. When a complete table claims exactness, check raw matching and distinct groups if the chosen certificate depends on that exactness. Do not mark a mathematical entailment independently verified merely because a response had a hash. The local verifier remains separate from the selector and black-box implementation.

### 8.4 Named closure, lazy atom construction

```text
atom_rel(A, ledger):
    if cache contains current complete relation for A: return it
    init sparse DSU over trace IDs (unseen IDs are implicit singleton roots)
    for every indexed named EQ(u,v,U) with A⊆U:
        union(u,v) retaining a proof edge if roots differ
    save relation and ledger-version metadata
    return DSU

named_match(i,B,ledger):
    # Incremental signature intersection; each C is a set of possible IDs.
    C = all positive IDs
    for A in atoms(B):
        R = atom_rel(A,ledger)
        C = C ∩ positives_in_class(R, i)
        if C empty: return NOT_FOUND
    pick x in C; return (x, proof-chain for each A)

named_target(P, ledger):
    for i in negative IDs:
        matches = []
        for B in P:
            if Zmax[i] contains a region covering B with named witness:
                matches.append(containment proof)
            else:
                match = named_match(i,B,ledger)
                if NOT_FOUND: break
                matches.append(match)
        if all B matched: return NO proof with one i and all matches
    return NOT_ENTAILED_IN_H only if complete named closure and consistent ledger
    otherwise return UNKNOWN
```

Equivalent batch version builds positive signature map once per B, then looks up negative signatures, typically faster when many negatives remain. Tuple/hash equality must be exact (resolve collisions; do not rely on probabilistic hash alone). Use candidate-specific atom DSUs: computing a relation at A only requires named regions containing A, not building all atoms globally. Cache current ledger-version data, so late equalities cannot be missed in a result advertised as complete. Under a budget the DSU may contain fewer edges; equality it proves remains sound, but absent edges then do not certify maximality or produce exact countermodels. `Zmax` for a cheap NO proof can include anonymous zeros, unlike the named-signature exact test itself.

### 8.5 Anonymous closure and exact fallback

```text
compute_feedback_closure(ledger, target=None, budget, tier):
    run cheap antichain and explicit verdict checks
    while budget allows:
        apply E01-E10 lazily on relevant target blocks/atoms
        update sound domains, emitting reasons for each removed witness
        if target NO proof obtained: return it
    if target is None: return compact indexes and pending obligations
    if tier permits named exact closure:
        evaluate target in the least equality relation using licensed named facts
        # A NO in the relaxation is sound even with omitted anonymous zeros.
        if NO proof obtained: return it
    if tier permits complete anonymous closure:
        return case_split(target, ledger, relevant anonymous obligations, budget)
    return UNKNOWN

case_split(target, state, remaining, budget):
    if budget exhausted: return UNKNOWN
    if proven contradiction: return CONTRADICTORY_BRANCH with proof
    if current named/region facts prove target NO:
        return CLOSED_NO with proof (all completions of this branch fail)
    if remaining empty:
        construct full least atom relation, check all difference constraints
        if any violated: return CONTRADICTORY_BRANCH with proof
        # actual history entailment only when no obligations were omitted
        if target fails: return CLOSED_NO with named proof
        return CONSISTENT_ACCEPTING_MODEL (class assignment or constructed words)
    choose one unresolved obligation z with complete sound domain W_z
    record why every positive outside W_z was excluded (or W_z = all)
    for x in W_z:
        child = rollback/persistent state + assumption EQ(y_z,x,region_z)
        ans = case_split(target, child, remaining\{z}, budget)
        if ans is CONSISTENT_ACCEPTING_MODEL: return ans
        if ans is UNKNOWN: record unresolved child
        otherwise retain child proof
    if any unresolved child: return UNKNOWN
    return case-split proof with all domain alternatives closed
```

For the outer procedure, confirm actual ledger consistency first (raw facts or at least one fully consistent branch). `CLOSED_NO` may stop a branch without proving it has models; it is a proof of implication conditional on that branch. If no model exists globally, report INVALID_LEDGER, not universal incompatibility. A target failure proved under a relaxed subset of observations is sound; a SAT countermodel for that subset is NOT_ENTAILED only for the subset, not the full history. If omitted obligations cannot be checked in the model, return UNKNOWN for the full history. If complete H is considered and the candidate is structurally compatible in one model, the strongest history-only answer is not entailed, but the real corpus may still fail.

Avoid expanding `p^r` branches if an early containment proof closes the target, if a zero already has a proved named witness, or if identical exact group obligations can share a witness. A domain elimination based on violated known NEQ after adding an equality is sound by Theorem 2; it is not necessary to first prove a specific unary disequality. Rollback DSU can support speculative branches using union-by-size without path compression, or use persistent/copy-on-write atom DSUs. Never commit branch-assumed equalities to the global proven ledger. Memoize a branch only with its remaining obligations and normalized equality state; a hash collision requires exact comparison.

### 8.6 prove_incompatible entry point

```text
prove_incompatible(P, ledger, budget, allow_raw_replay):
    validate complete P and scope
    if ledger inconsistent: return INVALID_LEDGER
    if exact scoped NO exists: return corresponding proof
    if current structural NO cone covers P: return refinement proof
    if same-negative region cover exists: return P03 certificate
    if lazy named/anonymous closure proves structural I(P): return its certificate
    if raw replay enabled and budget remains:
        for each B: index positive projections of original words
        for each negative i: seek a positive match on every B
        if all blocks match for i: emit raw replay proof, return PROVEN_NO
        if exact scan finishes and no failing i: return RAW_COMPATIBLE
    return precise NOT_ENTAILED_IN_H if full history countermodel established,
           otherwise UNKNOWN
```

The raw fallback is a structural inference from available words, not an invocation or redesign of the external learner. It can be deliberately disabled to isolate the marginal value of feedback. It should never call `ProjectionOracle.row` directly or create a separate external block-query channel. Only complete partitions are submitted by the coordinator; all inference here is internal arithmetic on existing observations. All proof-producing routines must leave timeouts transactionally safe.

## 9. Complexity and engineering for 100,000 symbols / 10,000 traces

Let `n=|Σ|`, `t=p+q`, total input trace length L, `k=|P|`, `h` named equality region edges (star-compressed), `d` stored explicit disequality constraints (a group constraint can implicitly denote many), `z` active anonymous obligations, `m_i` number of maximal zero regions for negative i, `a(B)=|B|+binom(|B|,2)`, and `A_P=∑_B a(B)`. Let `M=∑_(EQ edge U) a(U)` be total atom incidences if all equalities expanded. Count region membership or containment separately; integer-mask operations are not constant-time when n grows.

| Operation | Conservative complexity / notes |
|---|---|
| Parse complete compact tables | O(kq + n + explicit groups/witness metadata) time for explicit coverage; streamed O(q + n) scratch per block, plus retained payload. Explicit row relation costs O(number of entries) just to read. |
| Region antichain insertion | O(m_i * containment_cost) naive; index by size and element postings. Worst-case antichain can be exponential in n. |
| Region cover P03 | O(k ∑_i m_i * containment_cost) naive; early negatives/block failure and inverted indexes improve workload, not worst case. |
| Dense named atom closure | O(n²t + M α(t)) time, O(n²t + M_proof) space for DSUs and proof edges (initialization/word RAM; α is inverse Ackermann). No expansion of disequalities required for proof of named NO once consistency is assured; exact consistency checks cost additional incidence processing. |
| On-demand named closure | For atom A, O(h * membership_cost + t_A α(t)) upper scan bound, plus unions of matching edges; `t_A` here counts inserted endpoints/operations, not total t. For A_P atoms this can be O(A_P h) index checks in worst case. Inverted region postings reduce candidate scans. |
| Exact named target | After relevant complete DSUs, O(t A_P) class-signature operations plus map lookups (expected hashing with exact equality checks; deterministic sorting adds log t), O(t A_P) naive signature storage; process one block at a time to reduce memory. A witness certificate may require O(A_P t) path edges in worst case, with DAG sharing. |
| Exact named consistency | Check each explicit D_B(u,v) by some unequal atom in L, worst O(∑ a(B)); a SEP costs p such checks; full group inequality can require O(q²a(B)) if expanded, or compare exact group signatures. Check promised disjointness and prior ACCEPT predicates separately. |
| Anonymous case closure | O((∏ |W_z|) * polynomial(named model size + target + constraints)) worst case; sequential DFS polynomial working state per depth, potentially exponential proof size. |
| Full Boolean encoding | O(n² t²) equality variables, O(n² t³) transitivity clauses if explicit, plus region definitions and ledger formula; can add transitivity/refinement constraints lazily with checkable proof. |
| Raw target replay | Naive per-block erasure O(k(L+t)) time, O(L+t) scratch per block; sparse ordered per-trace buckets can make projection materialization for a fixed P linear in L plus nonempty trace/block entries, but exact all-empty and membership handling must be specified and benchmarked. |
| Full lattice enumeration | Bell(n) partitions, superexponential in n. Not a production method. |

The named polynomial theorem refers to a single target and explicitly represented finite history, not universal polynomial time at 100k symbols. For n=100,000 there are 4,999,950,000 distinct binary restrictions. For t=10,000, merely a 4-byte class identifier for every trace at every binary restriction would consume about 200 TB (decimal), before DSU ranks, Python object overhead or proof data. An explicit `k=100,000`, `q=10,000` zero/free classification has 10^9 entries (125 MB even if packed to one bit per entry, potentially many GB with witness IDs). If the service insists on explicit per-column metadata, intake may dominate and no selector optimization can erase that input-volume cost. A reference-based or compressed table transfer must be part of the negotiated external interface; do not silently assume it.

### 9.1 Sparse-scale strategy

- **Never allocate all atoms.** For cost `c` relative to the singleton partition, there are at most `2c` symbols in nonsingleton blocks, and the number of within-block binary atoms is at most `binom(c+1,2)` (convexity; putting all c merges in one block maximizes pairs). Thus low-cost candidates need at most quadratic-in-cost binary checks, plus singleton evidence. For a mandatory-contraction quotient with large blocks, operate on original symbol IDs and use direct containment/raw witness proofs to bypass atom expansion; no blanket pair scan. Treat the stated cost bound in original alphabet, not incorrectly in quotient size.
- **Use adaptive set representations.** Sorted `uint32` vectors for small blocks, interval lists or Roaring-style compressed bitmaps for larger sets, dense bitsets only when warranted. Python int masks are excellent at small n, but storing n singleton integers with increasing high bits consumes Θ(n²) bits even before other indexes. For n=100k the raw bit-length sum alone is ~625 MB. Compact singleton IDs should be special cases.
- **Postings:** symbol→region IDs, region→named trace edges and negative IDs; test A={a,b} by intersecting postings. If one large region covers almost all symbols, explicit postings cost O(n) per region; adaptive complements or interval representation may be better. A region index must prove containment exactly, never with only Bloom filter or sketch positives. Bloom filters may accelerate candidate filtering only when a false positive is checked before proof.
- **Intern block and group identities.** Reuse one block representation across tables/history; represent identical negative incidence sets with shared bitmaps, grouped witness maps or dictionary-coded positive IDs. Archive exact response references once. Store free group stars compressed; generate group inequalities only when needed. For dense evidence, work on batches and stream proof validation, with disk-backed indexes as needed. Do not deduplicate original IDs out of the registry.
- **Use raw occurrence sparsity if available.** Sparse per-word symbol→positions supports ordered projections; merge position streams to preserve order. For unary/binary equality comparisons, exact counts and position order can supply witnesses without constructing full n-dimensional count vectors. Treat symbols absent from both words as proved equal only after input registry verifies their absence, not because a table omitted them. If absent from all words, unrestricted structural compatibility is invariant under adding/removing them from nonempty active blocks; leave unused symbols as singletons to maximize blocks, and always return them in every complete external query. Handle no-active-symbol edge cases separately. This is an existing raw-analysis result, not an extra feedback fact.
- **Short-circuit target proof.** Query cheap zero region indexes first. Pick a block with no direct evidence for each negative early; lazy named stitching can be tested only where coverage is missing. Ranking this internal proof work is a heuristic for compute order, not query ranking or a pruning assumption. A failed proof attempt produces UNKNOWN, not SEP. Raw matching lookup for anonymous zeros (existing `compact.py` strategy) is usually preferable to exponential opaque-ID reasoning on large actual corpora; label its cost separately.
- **Budget tiers:** L0 direct verdict/region cover; L1 named EQ transport and small-atom signature stitching; L2 exact named closure on demanded atoms; L3 bounded anonymous case exploration or proof-producing SAT on a reduced logical premise set; L4 optional exact raw target replay. Each may stop early with a proof. Exactness flags indicate whether all relevant atoms/edges/obligations were considered. Cache eviction never invalidates already materialized certificates. Do not claim exact closure from a budget-limited tier.

The 100k/10k target is an engineering requirement, not a worst-case theorem. Stress fixtures should include singleton partitions (many tables), few enormous blocks (many internal atoms), sparse repeated short words, high-entropy long words, many anonymous zeros, and adverse antichains. Section 10 gives measurements to collect. Existing 1,000-symbol result is insufficient evidence for 100k scalability.

### 10.1 Certificate grammar and verification

Every proof contains canonical sample fingerprint, alphabet mapping, schema/capacity scope, candidate partition, referenced response digests, and a topologically ordered DAG. Example structure (illustrative IDs, not a fabricated live response):

```json
{
  "version": "feedback-aefc-v1",
  "scope": {"sample_digest": "<actual digest>", "regime": "unrestricted"},
  "candidate": [["a", "b", "c"], ["d"]],
  "result": "PROVEN_NO",
  "root": "proof-9",
  "nodes": [
    {"id":"proof-1", "rule":"F01", "source":{"query":"Q1", "block":["a","b"]},
     "conclusion":{"EQ":["y1","x1",["a","b"]]}},
    {"id":"proof-8", "rule":"E04", "premises":["<all required atom proof IDs>"],
     "conclusion":{"EQ":["y1","x1",["a","b","c"]]}},
    {"id":"proof-9", "rule":"P03", "premises":["proof-8","<d witness proof>"],
     "conclusion":{"STRUCT_NO":[["a","b","c"],["d"]]}, "negative":"y1"}
  ]
}
```

The illustrative JSON intentionally abbreviates atom proof IDs; a real certificate must include every referenced node and all required atom equalities. Verifier logic must be independent of DSU/index code used by the producer. It can recompute connectivity from proof edges with a simple BFS, independently enumerate the required unary/binary subsets, compare actual projections of original words, or replay a propositional proof. It must reject circular nodes, missing atoms, wrong labels/IDs, inconsistent scopes, unverified domain exclusions, missing alternatives, and false containment. A region-derived equality can be replayed directly by projecting the two original words on the derived region (and optionally check provenance chains); do not falsify a source table by assigning it a larger region than it reported.

For a cheap region certificate, name a single failing negative and one region/witness per block. For an anonymous leaf with no positive ID, verify by direct lookup of a positive matching the negative on the region. For a named stitched equality, check every atom path edge via its source or raw projection; all chains must start/end at the stated IDs and use a region containing that atom. For proof by cases, verify that the declared alternatives partition the disjunction's full possible domain, every excluded positive has a checked impossibility proof, and each child root proves the same target NO under exactly its assumption or a contradiction. Child assumptions are scoped locally and discharged at the parent. Branch inconsistency may be demonstrated by a violated NEQ or a sound empty domain, never by mere absence of a match. Global consistency must be checked via the actual corpus or a separate feasible history model. An inconsistent response triggers an error rather than a global infeasibility certificate.

Minimal explanations: use shortest equality-chain paths in the currently stored proof graph as a useful local heuristic; minimal number of source responses for a block may differ from minimal number of chain edges. A deletion-minimal certificate can be obtained by repeatedly removing one premise and rerunning a **complete** entailment checker; monotonicity ensures one pass over retained premises suffices for inclusion-minimality (when a deletion first fails, it still fails after further removals). With a bounded checker, retain any premise whose removal is UNKNOWN. Such result is only reduced, not proved minimal. Minimum-cardinality explanation is a different optimization problem: even a region cover has a set-cover structure, so do not promise polynomial global minimization. Keep an inexpensive proof first; minimize only under separate budget. For SAT mode, regenerate the precise clauses from scoped facts and verify UNSAT with a proof format such as LRAT (Cruz-Filipe et al. [5]); do not trust a solver's `unsat` return without replay. A SAT countermodel must be checked against the exact formula and, when useful, reconstructed with Theorem 1. No SAT model licenses a real-world ACCEPT.

```text
verify_inference_certificate(cert, registry, log, schema):
    validate version, fingerprint, scope and complete target partition
    verify trusted raw sample or observation consistency as required
    recursively check nodes in topological order with explicit assumption context
    for source leaves: validate observed coordinates and raw projection semantics
    for atomic chains: validate each edge and containment, check endpoints/connectivity
    for E04: independently generate all singleton and unordered binary atoms
              require proof for every atom, or separately verify exact raw equality
    for E09/E10: validate all domain removals or all cross-domain disequalities
    for P03: require same negative ID and a licensed ZERO proof for every block
    for E11: require complete domain enumeration and each closed child proof
             check local assumptions are discharged
    for structural cone: verify refinement and structural scope
    for bounded exact NO: verify exact scoped status; no structural generalization
    require root proves precisely cert.target/result, with no open assumptions
    return VERIFIED (or INVALID / INCOMPLETE with explicit reason)
```

The original raw verifier's `Replay.fact` and `Replay.region` can be retained as a fast independent path for named equalities; if inference derives a new equality on a block not queried, extend the record format (e.g. `source="derived"`, proof reference), or independently verify it as raw equality and explicitly preserve its actual provenance separately. Do not pretend its table source contains the new region. The overall optimality certificate still requires coverage of every cheaper admissible partition and a real compatible incumbent; AEFC certificates prove exclusions, not global search coverage.

Therefore replacing a paid query with a verified AEFC NO cannot delete a compatible optimum. A completed external ACCEPT for P*, together with coverage of every cheaper admissible partition, certifies its optimality. If an unresolved cheaper partition remains because of budget/incomplete responses, report incomplete with incumbent and proved lower bound if available; do not claim OPTIMAL. This follows from finite exhaustive coverage and soundness, not an assumption that AEFC always resolves every candidate.

## 12. Limitations and open research questions

**Established in the supplied work:** unrestricted projection criterion, atomic discrepancy lemma, structural monotonicity, same-negative zero-region coverage, mandatory complement obligations, witness-rank bounds, exact one-positive/one-negative clique closure, finite corpus-compression reference test. The main paper separately establishes bounded fixed-partition decision procedures and capacity-sensitive constraints.

**New candidate contributions proved here:** atom-equivalence realizability with a polynomial length witness construction; exact least-model closure for named unrestricted histories; exhaustive witness-alternative closure for anonymous histories; complete finite Boolean model for arbitrary projection-predicate implications; identity-aware evidence retention and case-split certificates. The generalized anonymous-evidence hardness reduction establishes a boundary on an extended evidence language, not a lower bound for every actual NO history.

**Remaining open:**

- Complexity of implication for consistent histories restricted to the actual paper's NO protocol, especially anonymous fixed zeros without other raw disequality constraints. The generalized graph-coloring reduction does not settle this promised-history problem. Can special free-group structure yield a substantially faster exact algorithm?
- A compressed representation of atom-equivalence closure supporting large blocks and many histories without materializing Θ(n²) atoms. Could region-intersection graph connectivity or grouped trace classes yield faster signature intersection with replayable proofs?
- Exact minimal explanation optimization and better domain propagation that exploits negative groups without expanding all positive/negative comparisons. Quantify certificate size, not just query count.
- Characterize full exact zero-group availability in the actual external API. The paper describes groups by projection but does not specify wire-level fields or whether zero groups are separately disclosed. Obtain an explicit adapter agreement; no claim about currently running service behavior.
- A separate theory for bounded failure feedback if the external owner later exposes sound, unfiltered bounded tables or explicit collective obstructions. The present unrestricted theorem cannot be transferred by changing the interpretation of zero bits.
- Empirical 100k/10k scalability and marginal benefit of stronger closure in realistic histories. The small sweep found no strict improvements except targeted examples; real gains depend on history structure, existing raw preprocessing and the interface's actual witness fields. No universal scalability, speedup or query-saving guarantee is supported.
- No live black-box calls, no full planted benchmark archives, and no production integration were performed. The supplied audit and raw certificate replays validate existing software, not the complete proposed adapter and new proof checker. The supplemental script validates the central mathematical construction and examples, with an explicit small-case branch cap; it is not a hardened implementation.
