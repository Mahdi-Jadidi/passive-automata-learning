## A. Proof judgments and required guards

### A1. AEFC realization and atomic completeness (R02 §5)
PASS, conditional on arbitrary finite ordered words over a fixed alphabet with fixed trace IDs.

Label each occurrence by symbol and its rank within that symbol. Equality of each singleton fixes the label multiset, and equality of each pair fixes the relative order of labels of different symbols. Labels of one symbol are already ordered by rank. Thus unary and binary restrictions determine the entire projection. Empty projections always agree.

For realizability, necessity of R_ab subset of R_a intersection R_b is erasure. For sufficiency, use a common order of all unordered symbol pairs. Give each equivalence class of each pair a distinct fixed-width binary code; encode each bit by ab or ba. The segment has fixed counts, independent of class. Append one run per symbol, whose length is the unary class index. For any pair, every other pair segment projects to a fixed word independent of the ID. Its own segment lies at a fixed offset and encodes its class, and the suffix gives unary counts. Pair class equality implies unary class equality by refinement; converse equality of the projection implies pair class equality by the fixed offset. This establishes exactness, including repeated symbols and absent symbols in the declared alphabet. At n=0 all words are empty; no atom relation can distinguish IDs. t=0 is vacuous. The claimed length bound follows from the construction. This proof uses synthetic countermodels only, not actual input replacements.

GUARD: exactness fails as a completeness claim if arbitrary fixed literals, lengths, counts, bounded-state feasibility, or unknown corpus restrictions are added. E.g. distinct opaque IDs with no required equalities have distinct least signatures, but actual fixed words can both be a. Even with globally distinct opposite-label words, x=ab,y=ac have identical a projections; absence of a named equality does not imply a real separation.

### A2. Named least model and anonymous closure (R02 §5)
PASS. For each atom A, form the equivalence relation generated by named equality edges whose source region contains A. Every model contains those edges and their transitive closure. Binary-edge inclusion into each endpoint unary graph proves refinement. Each difference-monotone constraint true in any model remains true after decreasing equalities to the least relations; consequently if a difference constraint fails there, the named branch is inconsistent. The construction in A1 realizes the least relations. A target is forced structurally NO iff some fixed negative has a positive match on every block in that least model. If not, the realized least model is a countermodel, not operational ACCEPT.

Anonymous zero means existential positive witness. The full set of models is the union over all assignments of one positive ID to every such zero. Each branch uses A2. Universal entailment requires every consistent branch to imply target NO, not a shared failing negative across branches. At least one branch must be consistent; an inconsistent history is an error, not a vacuous global NO. A sound proof can drop whole constraints (relaxation), but cannot drop alternatives from a retained existential constraint without checking impossibility. Incomplete case search is UNKNOWN. All domains and equality proof atoms must be regenerated independently. Named source identities cannot be discarded because a region from another witness subsumes deadness. Fixed-zero columns are not necessarily equal to each other.

Strict named stitch: x=abcd, y=abdc, query ab|c|d, ac|b|d, bc|a|d. All blocks dead via x, so abc|d is dead by the atom characterization, despite no abc zero region. Strict anonymous example from R02 §6.2 reproduced by executable; both x1 and x2 witness alternatives survive. The raw corpus in that example is not the universe of opaque models. The full small-domain history sweep allows same/opposite-label duplicates as a generalized partial-evidence language; the targeted strict case additionally checks global opposite-label distinctness. Do not extrapolate strict-gain counts to actual external histories.

### A3. Disjoint first-true branching (R03 §4)
PASS. At parent R(E,D), let e_1,...,e_t be allowed distinct unordered original-endpoint pairs. Partition every completion by the first satisfied e_j, or by no satisfied pair. Child j adds equality e_j and all earlier disequalities. These classes are disjoint; their union plus the all-false residual is exactly the parent, by construction. This proof does not rely on canonical merge parents. Empty children are allowed and may be omitted only with a checked contradiction. If the conflict is necessary, all-false is incompatible; otherwise it remains. The all-pair fallback leaves exactly E in the residual (if parent is consistent); exact NO can close E only, UNKNOWN cannot close it. D is branch-local and original endpoints must remain identifiable under rollback. An E-only cache key is invalid.

Adversary: X={a,b,c}, Y={epsilon}. Only abc is compatible. The dead partition ab|c supplies crossing pairs ac,bc; a canonical-parent tree whose first merge for abc is ab misses it if combined with conflict-only branching. Requiring all conflict pairs rather than at least one is also invalid. Omitting a cursor suffix or exact pending E can silently lose coverage.

### A4. Restricted rank packing (R03 §6.3)
PASS. Fix any final block B on current quotient vertices and a fixed anchor b in B. For every support S, max(0,|B intersection S|-1) <= |(B minus {b}) intersection S|. Multiply by lambda>=0 and sum. Vertex capacities bound the right side by |B|-1. Sum over final blocks, use local certified floors and take the ceiling because rank is integral. This is an inequality for any partition, independent of feasibility or how the local floors were obtained. A rational feasible weight vector suffices; no LP optimality assumption. Check rational signs, denominators, capacities, supports and each local floor independently. Use current quotient IDs; never reuse an ancestral additional bound after adding its cost to a descendant, but inheriting an absolute floor is safe.

Strict example: X={abcdef}, Y={badcef,abdcfe,bacdfe}. Supports abcd,cdef,abef each require rank >=1. Every vertex is in two supports; lambda=1/2 gives ceil(3/2)=2. Joining ab and cd attains cost 2, and exhaustive enumeration confirms it. In contrast, summing all three unit floors gives an invalid bound of 3.

Local floor guard: retain only full support/alternative families contained in S; never intersect arbitrary alternatives with S and treat the result as necessary. X={b},Y={epsilon}, alphabet {a,b}: deletion of {a,b} is a valid witness; truncating it to {a} falsely requires a in the separating block (b alone suffices). A feasible transversal is an upper bound on the minimum, not a certified lower bound. A restricted-column minimization LP can overestimate the unrestricted relaxation.

### A5. Witness rank, sparse evidence, policy (R01/R03/R04)
PASS under stated scope. A full discrepancy family for each opposite-label pair consists of unequal-count singletons and unequal-order binary atoms among stable symbols. For each negative, all chosen alternatives must be joined in one block. Their induced components refine any feasible partition witnessing these choices; conversely those components themselves satisfy every chosen alternative, and any retained disequalities not contradicted by a component. Thus minimum induced rank equals exact structural optimum for full families and a relaxation bound for partial necessary obligations. Nonempty-alphabet condition matters when positive list is empty: if n=0 and there is a negative, no separating block exists, even though a family list is empty. Both reports explicitly address this; check it before invoking vacuous-obligation routines.

The three-way sparse deletion join is complete only after excluding global opposite-label duplicate words and exhausting literal collision resolution, including absent-on-one-side joins. Mandatory same-negative group contractions are necessary by erasure; neither cross-negative mixing nor a single deletion entails a specific union. Occurrence-rank inversion tests and exact support are sound: after unequal-count symbols are removed, a restricted projection differs exactly when the retained positions in the other word are not increasing. The inversion endpoints plus unequal-count symbols are precisely the support of minimal atoms. R01's greedy equal region is inclusion-maximal, not maximum. No full production sparse index or resource guarantees are established here.

CDAQ conditional cone and incumbent cutoff proofs are sound for strict-improvement search in a fixed sample, with nonnegative weights, and verified structural NO or external ACCEPT. For NO all refinements are dead; for verified ACCEPT costs >= incumbent cannot strictly improve. The minimum of those two gains is conditional on a conclusive response and on the same sample/weights. The history-amplified minimum must range over a certified superset of possible failing negatives. Scores cannot certify coverage, and a persistent UNKNOWN can yield zero progress. All-optima mode uses strict greater-than cutoff. Scheduling requires fairness and eventual conclusive completion; no universal logarithmic query bound follows.

## B. Additional executable countermodels and integration requirements

Two explicit bounded-DFA counterexamples were found by enumerating every total DFA with one or two states per block, every accepting-state set, and initial state 0 (renaming makes this WLOG). These are local mathematical fixtures only.
- Fine YES / coarse NO: X={ab}, Y={epsilon,a,b}, partition a|b feasible at bound 2 per block (each local machine accepts words with at least one own symbol), but ab as one block is infeasible at bound 2. A two-state DFA rejecting epsilon,a,b must stay in its sole rejecting state on both a and b from the initial state; hence rejects ab.
- Fine NO / coarse YES: X={a,b}, Y={epsilon}. Each singleton sees epsilon as a positive projection, so cannot reject epsilon; the merged block accepts nonempty words and rejects epsilon with two states.

Other regression fixtures:
- Dead region union: X={ab,cd}, Y={epsilon}; ab and cd dead, union separates.
- Cross-negative mixing: X={epsilon}, Y={a,b}; a|b is compatible despite a dead for b and b dead for a.
- Same counts but different order: X={ab}, Y={ba}; ab separates.
- Missing collision guard: X=Y={a}; all group-deletion equalities hold, even for groups absent from both; globally infeasible rather than ordinary sparse join.
- Empty alphabet, no positives, one negative epsilon: infeasible; do not return cost zero by vacuity.
- Bounded exact NO or malformed receipt cannot prove structural NO. Structural optimum and operational optimum must remain separate. Require authenticated external receipt for operational ACCEPT and exact sample, partition, regime and capacity scope. A toy reference checker cannot establish receipt authenticity.
