## Request and identity
One complete partition of declared original alphabet, including unused letters; nonempty pairwise disjoint blocks, no duplicates or unknown symbols, union equals alphabet. Empty alphabet extension requires explicit owner approval. Original positive/negative IDs and ordered sequences immutable; do not dedup IDs or replace symbols with quotient IDs. Canonicalize block identity only, not traces; preserve response negative-column order. Request/attempt ID, schema, sample digest (including alphabet, label, IDs, order), partition identity, regime/capacity digest, admissible family, service version are bound to response. Raw bytes and digest stored by transport; retry has new attempt ID. Verify against expected immutable request, not fields merely echoed by untrusted responder. Authentication and digests are transport duties; echo comparison alone is not authentication. Reject replay against a different attempt. Contradictions between independently validated facts quarantine ledger rather than imply all partitions impossible.

## Status / action
* PROJECTION_NO: one original negative has positive equality witness for every submitted block; complete unrestricted base tables as described below. Even in bounded run this is structural, excludes all refinements. Independent raw replay can establish structural NO without a complete external receipt, recorded as RAW proof only.
* ACCEPT: external completed success bound to request, one complete DFA per submitted block; verify alphabet, total deterministic transitions, initial/accepting states, positive projections all accepted, at least one rejecting component per negative, and state limits if applicable. Bounded joint row if supplied must match those same DFAs. No tables required; local projection pass or simulator ACCEPT is not an external incumbent.
* BOUNDED_NO: only authenticated, conclusive exact failure after bounded check for exact partition/sample/capacities. No refinement or coarsening inference; no assumption of additional explanations. Independently verified structural facts may still be used.
* UNKNOWN: timeout, interruption, malformed, unauthenticated, mismatched, ambiguous NO, unresolved reference, incomplete artifacts. No semantic rejection; preserve pending candidate and attempt log. Trusted separate exact verdict with malformed optional feedback may be stored as scoped exact-only fact (no table ingestion); strict reference implementation may instead return UNKNOWN. Never convert UNKNOWN to NO by retry exhaustion.
* A bare generic conclusive NO needs independently authenticated semantics before it can be stored as scoped exact-only; otherwise UNKNOWN. Do not label as bounded failure unless bounded exact semantics are established.

## Tables and witnesses
Eq.23: bit 0 means local acceptance, bit 1 rejection. Complete R-infinity base table has fixed-zero columns exactly those whose projected word matches a positive; remaining columns partitioned by exact ordered projection equality into nonempty free groups. All 2^k bit assignments across k free groups feasible, including all-zero row; not a selected row, not a bounded/conditioned/reduced relation. One arbitrary row cannot identify fixed zeros. Explicit zero group equality/distinction not inferred from constant zero columns. Named witness required for failing negative on every block, not all zeros. Other zeros can be anonymous (existential positive), resolve by literal raw lookup with RAW_LOOKUP provenance if desired. Validate no missing, duplicate, wrong-ID columns, no wrong-block or missing block, exact free grouping (including distinct projections between groups), named positive ID equality; reject all table evidence atomically on malformed bundle. Negative-order list exactly expected original IDs (wire permutation requires separately negotiated explicit mapping). Reference data must be resolved and bound to same sample/block/table type/version before use. No row enumeration needed; never interpret bounded rows as unrestricted evidence. Raw check can reconstruct facts but must not mislabel them as external. Complete row coverage is insufficient without checking actual projections.
