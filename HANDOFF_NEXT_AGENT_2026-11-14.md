## Research question and formal model

The user wants a **fundamental, exact, independent method**, not a heuristic or a dispatcher whose backend merely accelerates the old RGS/DP/hybrid methods. The finite alphabet Σ is explicitly declared and ordered; IDs are opaque atomic nonempty strings, not characters. Words are finite lists of IDs and can be ε. Inputs are finite positive and negative sets of complete words, with first-occurrence normalization of duplicates. Every declared ID, including one absent from all samples, must belong to exactly one block. Blocks are nonempty and disjoint. The number K of blocks and the state counts of the regular factors are unknown and unrestricted. Each block owns an independent regular factor, and a word is accepted if all factors accept their projections.

For B⊆Σ, write `H(B) = {projection(p,B): p∈P}` and `R(B) = {n∈N: projection(n,B)∉H(B)}`. A partition Π is compatible exactly when `union(R(B) for B in Π) = N`. Necessity: every factor must accept each positive projection; each negative therefore needs a block whose projection differs from **all** positive projections. Sufficiency: use the finite regular languages H(B) as factors. The quantifiers are `for every n, there exists one B, such that for every p the projections differ`; do not interchange them. If B⊆D, R(B)⊆R(D), so coarsening a compatible partition preserves compatibility.

The objective is maximum number of blocks, denoted k*. `C` is the number of all compatible partitions; `O` counts all partitions with k*. `C=1` means sample-family uniqueness; `O=1` means unique sample optimum. Neither proves the physically true ownership, and global language knowledge can still fail to identify decomposition: Σ* can be implemented with one universal factor or universal singleton factors. No statistical law, noise model, fixed K or factor-state bound is implicit.

Contradictory positive and negative words make the sample infeasible. For nonempty Σ and disjoint labels, the single-block partition is feasible. If Σ is empty there is one empty partition, and the empty conjunction accepts ε; it is feasible iff N is empty. If Σ is nonempty and P or N is empty, every partition is compatible. Bell(0)=1. A finite exact algorithm remains possible despite NP-hardness; an always-polynomial exact method for arbitrary inputs would have the corresponding P-versus-NP consequences, not an unconditional impossibility proof.

## Validated foundations and counterexamples

The V32 synthesis and its source dossiers are the principal proof references: `results/2026-11-12/partition_methods_v32/integration/REPORT_EN.md`, `COMPARISON.md`, and packages A/B/C. The exhaustive canonical enumeration, anchored coverage-state subset DP, set-partition ILP and SAT formulations preserve the stated finite-sample model under their respective proofs. DP state D(S,U) partitions remaining IDs S while covering uncovered negatives U; a least-ID block anchor prevents duplicate partitions. Its generating polynomial is not a polynomial-time claim. Exact branch-and-bound pruning depends on the desired output: pruning ties can preserve one optimum while losing O and first optimal witnesses; pruning lower-objective branches can lose C.

For Σ={a,b,c}, P={ε,abc}, N={a}, the compatible partitions are `abc`, `ab|c`, `ac|b`. Greedily merging b,c first leads to one block and misses the two-block optima. There is no universally forced pair, yet the all-singleton partition fails, showing that pairwise must-link information alone is incomplete. This refutes only specified rules, not all graph methods. Selecting one sample-consistent automaton or one physical factorization cannot recover the entire compatible partition family.

Five separately scoped graph results: (1) sound forced-pair components give the whole family of their coarsenings only if the component partition itself passes the criterion; then C=Bell(q), k*=q, O=1. (2) A candidate-block conflict graph is bijective only with both symbol and negative coverage side conditions; it has exponentially many potential vertices. (3) Per-negative minimal **nonempty** rejecting hyperedges are exact when each negative has an edge contained in some block; count partitions, not witness hyperedges, and handle P=∅ and Σ=∅. (4) For graph G with nonempty E, Σ=V, N={ε}, P has an endpoint word for each edge: a rejecting block is a vertex cover and k*=α(G)+1. Bipartite matching gives the optimum for that restricted family, not general counts. (5) A polynomial projection circuit and SAT-to-clause-occurrence graph provide threshold-decision equivalence, not a parsimonious direct graph objective or automatic counts. Single-instance standard unweighted graph optimization with the full counting contract was left OPEN in that dossier. A failed direct coloring/cut representation does not refute all graph gadgets.

For mixed-cover hypergraphs, candidate block rows require **exactly one** covering row per symbol and **at least one** row rejecting each negative. An exact-cover requirement for negative tags is too restrictive when rejection sets overlap. Algorithm X branch histories or alternative rejection witnesses must not be counted as different partitions. SAT labeled slots create permutation symmetry; full gate equivalences or projected counting handle auxiliary variables, but projecting auxiliaries alone does not remove slot permutations. Neither an optimum nor a proof of SAT by itself supplies C/O or canonical-first witnesses.
